## 1. EGVLA2에서 얻은 기술적 시사점 → EGVLA3 설계 원칙
| # | 시사점(근거) | 설계 원칙 |
|---|---|---|
| 1 | 헤드 구조는 정확도를 거의 안 바꾼다(FM≈MLP 회귀, 차 ≤0.003). 같은 위치 오차는 사람 변동성 한계(10.4° vs 9.8~12.8°) | 헤드 복잡도보다 **지각(그라운딩)·데이터 다양성**에 투자 |
| 2 | 남은 오차는 일반화(안 본 목표 위치 16.9°)와 **경로 의도를 잘못 읽는 체계적 오류** | 경로 의도를 **명시적 입력**(상위 계획이 결정)으로 |
| 3 | 에피소드 시작 구간은 다봉(샘플 47%가 45° 이상 갈림), K 평균이 모드를 뭉갬 | 모호성은 하위 정책이 아니라 **상위 결정(경로·서브골 선택)과 commitment**로 해소 |
| 4 | 서브골은 정확도엔 ≤0.4°지만, 드롭아웃 학습 시 결측에 견고 | 서브골 = **상위·하위 사이 인터페이스**. 결측·지연을 견디도록 드롭아웃 학습 |
| 5 | 지연의 94%가 Florence-2 그라운딩(젯슨 821ms), FM 헤드 54ms. 청크 뒤 스텝으로 지연 보상은 오히려 나쁨 | 느린 추론은 **제어 루프 밖(비동기)**, 하위 제어는 최신 지각으로 반응. 지연 정보를 입력으로(TIC-VLA식) |
| 6 | 서빙 입력(JPEG q80)만으로 방향 4° 어긋남, 응답 직렬화 버그 | **학습-서빙 동등성 점검을 파이프라인 표준**으로 |
| 7 | 오프라인 방향 오차는 다른 정당한 경로를 오답으로 친다 | 평가는 **SR·CR·시간 + 리플레이 시뮬레이션**, 사람 일치도 천장으로 해석 |
| 8 | 학습은 pos1 단일 시작 위치, 한 장소 | **반전 증강·시작 위치·장소 다양화**를 데이터 계획 기본값으로 |

## 2. EGVLA3 후보안
### 안 1 — 지시문 조건 EGVLA ("진짜 VLA", 교수님 요구 직결) [추천: 먼저]
- 지시문 → (대상 phrase, 경로 의도) → **Florence-2 phrase grounding**으로 임의 대상 bbox(서브골) → EGVLA2 하위 제어.
- 핵심 아이디어: 언어를 텍스트 임베딩으로 헤드에 넣지 않고(CLIP·one-hot은 이득 없었음) **그라운딩 phrase로 지각을 바꿔서 행동을 바꾼다**. 서버에 이미 phrase별 정지 면적 맵(GOAL_AREA_MAP)이 있어 다중 대상 확장의 발판이 있음.
- 필요: 대상 2~3종 배치 장면에서 "○○로 가" 수집(대상별 에피소드), 경로 의도 토큰(좌/직/우) 실험.
- 판정: 같은 장면에서 지시문만 바꿨을 때 목표가 바뀌는 비율(지시 따르기 성공률) + SR.

### 안 2 — 에이전트형 2층 (상위 계획 + 하위 제어, 비동기)
- 상위(느림, 원격 서버 또는 젯슨 저빈도): 장면 이해·대상 선택·경로 의도·서브골 순서·복구 전략(대상 소실 시 탐색)을 결정. 도구 = 그라운딩 호출, 도착 판정, 회전 탐색.
- 하위(빠름, 온보드): EGVLA2 계열 경량 정책이 최신 프레임 + 상위가 준 서브골·경로 의도로 연속 액션.
- 인터페이스: 서브골 bbox + 경로 의도 + (선택) 지연 메타데이터. 드롭아웃 학습으로 상위가 늦거나 끊겨도 버티게.
- 근거: 시작 구간 모호성(③), 지연 구조(⑤). 외부 사례: π0.7(서브골 생성), NaVILA(중간 언어 행동), TIC-VLA(비동기·지연 입력), Gemini-ER/On-Device(추론·실행 분할).
- 위험: 상위 모델 지연·비용, 평가가 복잡해짐. 남겨둔 주제 73-4-②(온디바이스 분할)와 직접 연결.

### 안 3 — 경량화 극한 (Raspberry Pi 방향, 논문 방향 직결)
- Florence-2 그라운딩 비용(beam·토큰) 축소 → int8 → 소형 검출기 증류 → Pi CPU 지연 측정.
- 하위 정책은 이미 작음(헤드 0.2~0.7M). 병목은 지각.

## 3. 제안 순서
1. **EGVLA2 실기 검증(P2) 완료가 선행** — EGVLA3의 기준선.
2. 안 1(지시문 조건)을 EGVLA3-α로: 데이터 소량(대상 2~3종 × 위치 × 10~20) + phrase 교체 실험. 교수님 요구 해소.
3. 안 2는 안 1의 상위 계층으로 단계적 확장(β). 처음엔 규칙 기반 상위(대상 선택·탐색)로 시작해 VLM 상위로 교체.
4. 안 3은 논문 경량화 축으로 병행.

## 4. 결정 필요(사용자·팀)
- EGVLA3 정의를 "액션 헤드 트랙"에서 **"지시문 조건 + 2층 구조"**로 바꿀지
- 교수님 요구(지시문 따라 행동 변화)를 EGVLA3의 1차 목표로 둘지
- 다중 대상 데이터 수집 가능 여부(대상·배치·수량)
- 상위 계획을 원격 서버에 둘지(온디바이스 분할) — 경량화 논문 주장과의 충돌 여부
