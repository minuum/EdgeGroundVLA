핵심 발견

5개 세션에서 도출된 실사 결론

✅

Decomposition 모델은 실제 접근 가능

Session B·C 모두 바스켓에 성공적으로 접근. 프레임 가득 채우는 "도달" 행동까지 확인. 시뮬레이션 66.7% success rate가 실사에서도 재현됨.

⚠️

FWD+LEFT 편향 — 출발 각도에 민감

Session A는 동일 타깃 동일 거리에서 완전 실패. FWD+L 누적으로 왼쪽 벽으로 이탈. 초기 포즈 ±10° 차이가 성패를 가름.

🚫

exp49 regression 모드 완전 비동작

exp49 모델이 regression 출력 ≈ −0.015로 수렴. 사실상 로봇 정지. 분류 헤드 없는 순수 regression만으로는 현재 설정에서 동작 불가.

📊

레이턴시 430ms — 실사 허용 범위

checkpoints/best 모델의 스텝 레이턴시 평균 430ms. bang-bang 0.45s 간격과 맞아 실사 제어에 문제 없음. exp49는 오히려 385ms로 더 빠르나 출력이 무의미.

🎯

Bbox grounding이 접근의 핵심

성공 세션에서 바스켓이 화면 오른쪽으로 이동했음에도 추적 유지. Kosmos-2 기반 bbox cx 추적이 Stage2 입력에 제대로 반영된 결과.

🔄

Stop 조건 부재 — 다음 과제

Session B·C 모두 바스켓에 충돌할 때까지 전진. Area threshold stop 조건이 실사에서도 반드시 필요. 현재 대시보드 bbox area 0.18 기준 적용 예정.
