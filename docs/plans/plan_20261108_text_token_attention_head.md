> 상태: 사용자 요청으로 실행. 오프라인 전용. 비교군은 T4와 같은 어휘(정상40+부정40)·같은 평가.

## 목적
T4(V4)는 융합 인코더의 텍스트 토큰을 **평균 풀링**해 헤드에 넣는다. 평균은 문구의 순서·핵심 단어(물체 이름)를 흐린다. 토큰 단위로 두고 **이미지 특징이 질의(query)가 되는 크로스 어텐션**으로 읽으면 동의 표현에 더 강건한지 확인(T4 잔여 약점: 동의 표현 정지 +3.1%p, 명령 변화).

## 변형
- V4: 평균 풀링 [이미지 768 ; 텍스트 풀링 768] (T4 그대로 재사용, 같은 시드·분할)
- **V5**: [이미지 768 ; 어텐션 풀링 768]. 어텐션 풀링 = MultiheadAttention(4 heads, d=768), query = 이미지 특징(Linear), key/value = 융합 인코더 은닉의 마지막 6개 토큰(문구 토큰 + `</s>`), 헤드와 함께 학습. 나머지(PiZeroFM·서보 라벨·드롭아웃 30%·120 epoch·부정 20%)는 V4와 동일.

## 파일
`scripts/precompute_text_tokens.py`(토큰 캐시, 프레임 간격 9) → `runs/egvla2_fm/text_vocab_tokens.npz` / `scripts/eval_text_cond_t5.py` → `docs/v5/egvla2_fm/text_cond_t5.json`(V4 재학습 포함 = 같은 조건).

## 성공 기준(사전 선언, T4와 같은 기준)
부정 정지 ≥90% · 동의 표현 명령 변화 ≤0.10 · 동의 표현 정지율 ≤ V0+3%p. V4 대비 동의 표현 정지율이 낮아지면 개선으로 기록, 아니면 "어텐션 헤드의 이득 없음".
