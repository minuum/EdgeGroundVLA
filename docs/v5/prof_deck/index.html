3-2. 무엇을 "성공"이라 했나 — 판정 근거

성공의 정의는 현장 관찰자의 수동 기록. 영상 bbox로 그 기록을 사후 교차 확인
A3 성공 세션: 타깃을 정면에 두고 접근, 마지막 프레임에서 바구니가 화면 하단 중앙을 채우며 정지
구분기준
정의(수동)현장에서 사람이 기록한 결과 열(성공/실패)
성공 세션의 영상 특징마지막 타깃 면적 0.20~0.34(정지 기준 0.25 근처), 타깃 소실 0프레임, 평균 13.5스텝
실패 세션의 영상 특징타깃 소실 · 과접근(면적 0.45 이상) · 엉뚱한 물체 추종(A1·A2 실패 16건)
한계: 서면 판정표가 사전에 없었고(핸드오프에는 소실률·정지 거리·성공률 기준만 기재), 조건별 연속 블록이라 판정이 블라인드가 아니었을 가능성이 있다. 그래서 영상 지표로 교차 확인했고, 로봇 측에 실제 사용한 판정 문구와 정지 거리(FPE) 기록을 요청할 예정.

3-3. 목표 위치별 성공 사례 — 시작(pos1)에서 도착까지

A3 성공 세션 중 경로마다 1개(해당 경로 성공 세션의 스텝 수 중앙값에 가까운 것), 진행 1/5~5/5 시점
공통: 멀리 보이던 바구니(면적 0.02~0.03)가 점점 커져 0.22~0.26에서 정지
· 시작 위치는 전부 pos1 (pos2·pos3 미시험)
· 중앙 행은 마지막 프레임에서 바구니가 화면 오른쪽으로 치우쳐 있음 — 수동 기록은 성공. 정지 위치 정확도는 FPE 기록 필요
선택 규칙을 미리 정해 뽑은 사례이며 결과가 좋은 것만 고른 것이 아님

6. 평가 코스 — 단계별로 무엇이 가려졌나

오프라인으로 후보를 거르고, 선택은 실기로
단계측정알려준 것한계
① 오프라인 방향 오차사람 방향과의 차이A3 +22° → 선택 기준 부적합사람 조작=정답 가정
② 반사실 민감도 S타깃 cx ±0.2 이동 시 행동 변화서보 라벨↑ → S↑오프라인 지표
③ 구조 비교E2E·월드모델 3분할대체안이 기존 방식을 못 이김저예산 변형만
④ 실기 폐루프수동 성공 + H5 교차 확인A3 63/63ASYNC·EMA 0.0, pos1
다음 단계(로봇 측 핸드오프 문서로 전달): A3 pos2·pos3 일반화 → SYNC·EMA 0.5 합의 설정 시험 → 속도 정렬
