# 분석: 회전·이동의 물리 효과 — 실기 드라이런(10/22) vs 학습 데이터 (2026-10-23)

## 1. 회전: 학습 데이터 vs 로봇의 물리 효과 (지표 = 이미지 속 타깃 cx 변화, 도·cm 환산은 카메라 화각 미확인)
| | 학습 데이터(사람) | 로봇(SYNC, 모델 명령) |
|---|---|---|
| 회전 명령 크기 | 기록 az ∈ {0.4, 0.7, 1.0}(평균 0.72) | az = ±0.25 고정(rotate_az) |
| 구동 시간 | 연속 3프레임 ≈ 0.38초 | 0.4초 버스트(램프 0.05초 포함) |
| 타깃 cx 변화 | az>0: −0.152(n=465), az<0: +0.166(n=334) | az>0: −0.207(n=15), az<0: +0.152~0.302(n=5) |
| **단위 명령·시간당 효과**(Δcx / az·초) | **0.54**(중앙값) | **2.07~2.37** |
→ **같은 az 숫자라도 로봇이 약 4배 더 돈다.** 로봇의 az=0.25 한 번(0.4초)이 사람의 az≈1.0 수준 회전과 비슷하다. 기록 az(0.4/0.7/1.0)는 속력 단계(lx·ly와 같은 레벨)이지 로봇 twist.angular.z와 1:1이 아니다(대략 로봇 az ≈ 기록 az × 0.26: 0.4→0.10, 0.7→0.18, 1.0→0.26).
- **부호**: 회전 후 방향이 맞게 나옴(az=+ → cx 감소, 타깃이 오른쪽→중앙). 정정 전 세션 1건(203035)은 반대로 돌아 cx가 0.76→0.97로 밀림.
- **한 번에 얼마나**: 시작 cx 0.75~0.76에서 az=+0.25 한 버스트 후 0.54~0.55, 두 번째에서 중앙(0.50) 도달(세션 204813·204948) — 현재 고정 az는 우연히 한 버스트에 −0.2 정도라 중앙 수렴에 쓸 만하다. 다만 시작 cx가 0.87~0.88이면 두 버스트 후 0.36까지 **오버슈트**(세션 205118·210745: 0.87→0.68→0.43→0.36).
- **잔여 회전**: 회전 직후 명령 0 스텝에서도 같은 방향으로 Δcx ≈ −0.04(n=4)가 더 움직임(관성·카메라 지연 중 하나, 구분 불가).
- **사람의 회전 시간**: 연속 약 0.64초(5프레임 중앙값). 로봇은 버스트 사이 추론 지연(약 0.9초) 때문에 같은 회전에 약 3초.

## 2. 이동(strafe·전진): 학습 vs 로봇
- ly 부호: 두 쪽 모두 **ly<0이면 cx 증가**(학습 +0.009, 로봇 +0.024), ly>0이면 감소 → 데이터와 로봇의 ly 부호 규약은 일치(az와 같음).
- 크기: 로봇 쪽 효과가 약 2.7배 크다. 단 로봇 명령은 단위 방향×1.15·속도 0.7 고정이고 학습은 크기 레벨(0.4/0.7/1.0)이라 같은 조건 비교가 아니다(대각선 포함). 속도 보정식(v=6.59+19.85·s cm/s, 직선 30회)은 전진 기준.
- **보정 방향 비율**: cx가 중앙에서 0.1 이상 벗어났을 때 중앙 쪽으로 strafe한 비율 — 학습(사람) 44.5%(n=7,559), 로봇(모델) 36%(n=253). **사람 데이터 자체가 타깃 중앙화를 하지 않는다**(곡선 경로를 의도적으로 따라감). 그래서 모델도 cx 피드백으로 서보하지 않는다.
- 폐루프 증상: 세션 210745에서 회전으로 cx 0.36까지 간 뒤 ly≈−0.8 strafe를 10스텝 내내 유지, cx가 0.36→0.96으로 단조 증가하다 화면 밖으로 나가 bbox를 잃음(소실 5프레임 → 탐색). 세션 204813도 중앙(0.50)에서 시작해 cx가 매 스텝 +0.04~0.07 단조 증가.

## 3. 해석
1. **회전 크기는 물리 보정이 필요하다**: 기록 az ≠ 물리 az. 현재 고정값 0.25는 한 버스트 약 −0.2 cx(≈사람 시작 회전 전체)로 우연히 쓸 만하지만 시작 cx에 따라 오버슈트한다.
2. **모드 의존**: SYNC는 0.4초 버스트라 위 수치지만 ASYNC는 다음 응답까지(약 0.9초 이상) 계속 돌아 같은 az로 2배 이상 돈다(ASYNC 회전 사례는 데이터에 없음).
3. **서보 부재**: 학습 데이터가 경로 추종형이라 모델은 타깃을 향한 피드백 조향이 약하고, 표본 오차(방향 오차 지표)로는 이 폐루프 실패가 보이지 않았다.
4. 측정 한계: Δcx는 화각·타깃 거리에 의존, 회전 표본 n=15+5, 카메라 지연 미분리.

## 4. 제안(구현 승인 전)
1. **비례 회전**: SYNC에서 az_cmd = sign(cx−0.5)·clip(|cx−0.5| / 0.83, 0.08, 0.25) (0.83 = Δcx per az per 0.4초 버스트 = 0.207/0.25). cx 0.76 → 0.31→0.25 클립, 0.62 → 0.14. 잔여 회전(−0.04)은 데드존(0.08) 안에 흡수. ASYNC는 지속 시간 비로 az를 줄임.
2. **물리 보정 실험(로봇 세션)**: 정지 상태에서 az ∈ {±0.1, ±0.25, ±0.4}를 0.4초 버스트로 각 5회, 목표를 고정 두고 회전 전후 cx(또는 각도기·눈금)를 기록 → 회전 보정식(Δcx 또는 도 per az·초). ly·lx도 같은 방식(속도 보정 30회와 같은 절차)으로 ly 보정.
3. **서보 항 추가 검토**: 중앙 벗어남에 대한 strafe 보정(cx 피드백)은 모델 외부 규칙으로 추가할지 결정(학습 분포 밖 개입이라 비교군으로 분리 권장).
4. **데이터 해석 정리**: 기록 az 레벨을 물리 단위로 환산하는 표(위 0.26 계수)를 보정 실험 결과로 확정하면, 학습 데이터의 회전 시간·크기를 로봇 명령으로 재현하는 변환이 가능.
