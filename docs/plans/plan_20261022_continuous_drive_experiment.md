# 계획: 연속 구동(청크 실행) 실험 — 정지-이동 루프 vs 직전 명령 유지 vs 청크 스트림 (구현 승인 전)

> 작성일: 2026-10-22 | 상태: **계획(사용자 검토용, 구현 금지)** | 관련: CH78 ⚙️ 런타임 요인·🧠 π0와 비교, `latency_modes.json`, 대시보드 루프 `mona_dashboard.py`(약 1625행)

## 0. 목적과 가설
- π0는 청크를 open-loop로 이어 실행한다. 우리는 추론이 약 0.9초라 한 번에 0.4초만 이동하고 정지한다(한 주기 약 1.35초, 이동은 그중 0.4초).
- **가설**: 이동을 멈추지 않으면(연속 구동) 같은 거리를 더 짧은 시간에 가고 움직임이 부드럽다. 방향 정확도는 이득이 없거나 약간 나빠질 수 있다(오프라인).
- **반증 조건**: 성공률이 정지-이동보다 5%p 이상 낮거나 충돌·개입이 늘면 기각.

## 1. 근거(오프라인, 이미 측정)
| 방식 | 명령이 7프레임 오래됐을 때 방향 오차(같은 위치 / 안 본 위치) |
|---|---|
| 직전 명령 유지(hold) | 11.0° / 18.4° |
| 청크 뒤 스텝 사용(chunk) | 12.1° / 20.5° |
→ 정확도만 보면 hold ≥ chunk. 연속 구동의 이득은 속도·부드러움이어야 한다.

## 2. 비교군(실기, 한 번에 하나만 바꿈)
| 팔 | 구동 | 변경점 |
|---|---|---|
| S (현재) | 정지-이동: 판단 → 0.4초 이동 → 정지 → 새 프레임 | 없음 |
| H | 연속 hold: 판단이 올 때까지 직전 명령을 계속 수행 | 루프 변경 |
| C | 연속 chunk: 응답의 청크 8스텝을 8fps로 순서대로 수행, 새 응답이 오면 교체 | 루프 변경 + 청크 전달 |
- 모델·EMA·속도 규칙은 모두 현재 값으로 고정. 각 팔 pos1 × 목표 위치 5종 × 4회 = 20회(S는 이미 폐루프 본 시험이 있으면 그 결과 재사용).

## 3. 서버·로봇 변경(승인 후)
- 서버 `/predict` 응답에 `chunk`(K 평균, 8×(lx,ly), 단위 방향×속도 규칙 적용 후)를 포함. 이미 `chunk_first` 계열 필드는 있음(응답 필드 잘림 점검 필수).
- 대시보드 루프(의사 코드):
```python
# 구동 스레드(8Hz)와 추론 스레드 분리
while running:
    frame = latest_frame(); res = predict(frame)          # 약 0.9초
    with lock: plan = (res["chunk"], now()); stale_limit = 2.0
def drive_tick():                                          # 125ms마다
    with lock: chunk, t0 = plan
    i = min(int((now() - t0) / 0.125), 7)                  # C: 경과 스텝, H: i = 0 고정
    if now() - t0 > stale_limit: stop()                    # 안전: 응답이 2초 넘게 안 오면 정지
    else: send(chunk[i])
```
- 정지 판정(near-goal 면적 0.25, 소실 5프레임, 탐색)은 응답 처리 시점에 그대로 적용.
- 수정 파일(예상): `robovlm_nav/serve/mona_dashboard.py`(구동 루프), `vla_control_utils.py`(연속 명령 전송, 램프), `egvla2_fm_policy.py`(청크 반환은 이미 있음). 환경변수 `VLA_DRIVE_MODE=stopgo|hold|chunk`(기본 stopgo, 동작 변화 없음).

## 4. 오프라인 선행(실기 전, 로봇 불필요)
1. 리플레이 시뮬레이션(`eval_replay_sim_cont.py` 계열)에 구동 방식 3종을 넣어 **도착 소요 시간·누적 위치 오차·종점 오차**를 비교한다(지연 0.9초, 이동 0.4초 가정).
2. S 대비 H·C의 시간 단축과 오차 증가가 모두 작으면 실기 시험 가치가 있다고 판단.

### 4.1 선행 시뮬레이션 결과 (`scripts/sim_drive_modes.py`, 분석적, 로봇·모델 불필요)
사람 경로 길이 중앙값 218cm(p10 173, p90 279), 규칙 속도 0.7(20.5cm/s), 이동 0.4초·대기 0.45초 가정.
| 추론 지연 | S 도착 시간(판단 횟수) | H·C 도착 시간 | 배속 | H·C의 낡은 명령 이동 거리 |
|---|---|---|---|---|
| 0.5초 | 25.7초 (27회) | 11.4초 | 2.3배 | 약 10cm |
| 0.9초 (현재) | 36.5초 (27회) | 12.0초 | 3.0배 | 약 18cm |
| 1.3초 | 47.3초 | 12.6초 | 3.8배 | 약 27cm |
- **정지-이동은 이동 비율이 약 30%(0.4/1.35초)라 에피소드가 길어진다.** 속도 0.7에서 한 판단에 약 8cm라 약 27번 판단해야 한다는 계산이다.
- ⚠️ 이 판단 횟수(27회)는 EGVLA1 실기의 평균 11.64스텝과 크게 다르다. 원인은 미확인(EGVLA1의 판단당 이동량이 더 큰지, 사람 경로 길이 적분이 과대인지). **실기 로그에서 판단당 실제 이동 거리를 확인해야 한다.**
- 시뮬레이션은 시간 구성만 계산한 것이며 방향 정확도·충돌은 포함하지 않는다(방향은 위 오프라인 표 참조).

## 5. 평가 지표
- 성공률(SR), 충돌(CR), 개입 횟수, **도착까지 소요 시간**, 이동 거리, 멈춘 횟수, 궤적 부드러움(명령 변화량). 주 지표는 SR·CR, 소요 시간은 이 실험의 핵심 이득 지표.
