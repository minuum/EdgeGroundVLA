## Analysis

### 1. Pi-Zero 기반 로봇 주행 테스트 결과 및 한계
* **주요 성과:** Pi-Zero 모델을 활용한 실제 로봇 주행 테스트 성과를 인정받아 RISE 사업에서 은상을 수상함.
* **데이터 사양:** 동기식으로 수집한 18~20개 프레임의 에피소드 데이터 적용.
* **주요 병목 (Blocker):**
  * **조향 및 제어 불안정:** 액션 청크(action chunk) 버퍼 설정 및 청크 길이 문제로 인해, 주행 중 로봇이 목표 지점을 오버슈팅(passing by)하거나 과도하게 회전(over-rotation)하는 현상 관찰.
  * **연산 및 하드웨어 리소스 부족:** FP16 정밀도 실행 하에서도 24GB Swap file 설정을 사용했으나 서버가 다운되는 현상이 반복 발생하여, 물리적 실험 횟수가 극도로 제한됨.

### 2. Closed-Loop 오프라인 테스트
* **정량적 결과:** 2×200 범위 기준으로 목표 지점 0.2~0.3m 오차 이내 도달 정확도가 **96.2%**로 측정됨.
* **데이터셋 조건:** 추가 경로 데이터를 포함하여 총 223개 에피소드 학습 데이터 활용, 180개 학습 시점 기준 평가 수행.

### 3. PaliGemma 기반 객체 인식 및 LoRA fine-tuning 분석
* **LoRA 적용 상태:** 현재 SigLIP 레이어와 LM 레이어에 LoRA를 적용한 상태임.
  > 🔧 **정정 (2026-06-10):** 초기 기록의 "DINOv2 레이어 제외" 표현은 사실 오류로 삭제함. **PaliGemma2의 비전 인코더는 SigLIP(SigLIP2) 단일 구조이며 DINOv2를 포함하지 않는다.** DINOv2+SigLIP 이중 인코더는 OpenVLA/Prismatic 계열 구조로, 우리 backbone과 무관함.
* **텍스트 프레이즈 편차:** "grey basket" 대비 **"grey container"** 또는 **"target object"** 등의 텍스트 프롬프트를 사용할 때 그라운딩(grounding) 성능이 더 높게 관찰됨 (Cosmos 모델의 경우 텍스트 입력 문구에 따른 그라운딩 품질 편차가 상대적으로 작음).
* **OOD 환경 취약성:** 실물 테스트 진행 시, 학습 데이터 수집 당시에 없었던 새로운 객체 위치 배치나 새로운 그레이 박스 배치 시 인식에 실패하거나 궤적이 흐트러지는 행동 변화가 발생함.
* **주요 병목 (Blocker):**
  * 학습 데이터셋의 절대적인 부족 (총 224개 에피소드, 에피소드당 18~20프레임 내외).
  * 원거리/근거리 및 다각도 데이터 다양성 결여로 인한 OOD(Out-of-Distribution) 강건성 저하.

## Findings

1. **비전 그라운딩 강화 필요:** 객체 위치가 데이터셋 분포에서 이탈(OOD)할 때 그라운딩 성능이 급락함. → SigLIP 상위 레이어 LoRA 강화 + 데이터 증강으로 대응.
   > 🔧 **정정 (2026-06-10):** 초기 기록의 "DINOv2 frozen 불균형" 진단은 삭제. PaliGemma2엔 DINOv2가 없음(SigLIP 단일). 따라서 이종 인코더 정렬 왜곡 가설은 우리 backbone에 성립하지 않음.
2. **LLM 레이어 튜닝의 부작용:** 224개 소규모 도메인 데이터셋 환경에서 LM 레이어까지 LoRA 튜닝을 수행할 경우, 특정 텍스트 프레이즈에 과적합(overfitting)되거나 표현 제약으로 인한 일반화 붕괴(예: grey basket vs grey container 성능 차이)가 심화될 가능성이 큼.
3. **액션 버퍼 딜레이 및 청킹 불일치:** 동기 주행 중 발생하는 오버슈팅과 조향 지터는 로봇 측 동작 주기와 VLA 모델이 뱉어내는 액션 청크 길이(action chunk size) 간 미스매치에서 오는 축적 오차임.

## Conclusion & Action Items

### 1. PaliGemma LoRA 아키텍처 재설계
> 🔧 **정정 (2026-06-10):** 기존 "결정 사항 1(SigLIP+DINOv2 적용)"은 DINOv2가 PaliGemma2에 없으므로 **삭제**함. 비전 인코더는 SigLIP 단일이며, LoRA 강화는 SigLIP 상위 레이어에 집중한다. (exp64가 이 결정에 해당 — SigLIP 19-26 q/k/v LoRA, LM frozen)

* **결정 사항 1:** **LLM 레이어는 LoRA 학습 대상에서 전면 제외**하여 텍스트 프레이즈 과적합을 방지하고 비전 그라운딩 표현력 극대화에 집중함. (비전 인코더 LoRA는 SigLIP 상위 레이어에 적용)
* **결정 사항 2:** LoRA 재학습 적용 이후에도 새로운 객체(그레이 컨테이너 등) 인식 성능이 개선되지 않을 시, PaliGemma의 기본 프리트레인드 객체(pre-trained object classes)를 교체하여 데이터를 재수집하는 대안 검토. (→ 6/10 의자 객체 전환으로 진행)

### 2. 데이터셋 증강 (Data Augmentation) 및 스케일업
* **결정 사항:** 원거리/근거리 및 다각도 노이즈 극복을 위해 학습 데이터셋에 적극적인 데이터 증강(Augmentation) 기술을 적용해 데이터 실질량을 대폭 확대함.

### 3. 실제 로봇 주행 제어 최적화 및 평가
* **결정 사항 1:** 조향 오류 극복을 위해 VLA 액션 청크 생성 개수 분석 및 적정 액션 청크 길이 튜닝 실험을 순차 실행.
* **결정 사항 2:** 직선 및 곡선 경로, 그리고 다양한 객체 배치 위치별 성공률을 명시적으로 측정하는 실주행 테스트를 수행하고 주행 기록 영상을 촬영하여 최종 논문 메트릭에 반영.
* **결정 사항 3:** Cosmos 및 PaliGemma의 상호 대조 결과를 논문 템플릿 형식에 맞추어 정량적으로 정리.
