# 모델 세대 레지스트리 (PN 대장)

> 작성 2026-11-08. 출처: `runs/egvla2_fm/deploy/MANIFEST.json`, `logs/episode_log.csv`(origin/monavla-driving), `docs/v5/egvla2_fm/*.json`, CLAUDE.md, 계획서.
> **PN 체계는 제안안**이다(`EG{세대}-{순번}`). 이름·번호는 사용자가 확정한다. 아직 확인 못한 칸은 "미확인"으로 둔다.
> 실기 성공 = 로봇 쪽 episode_log의 운영자 수동 판정(블라인드 아님, 문서화된 성공 기준 없음, 좌우 정렬 미반영).
> **세대 간 오프라인 수치는 평가 방식이 달라 비교하지 않는다.** 직접 비교 가능한 축은 실기 성공(같은 프로토콜일 때)뿐이다.
