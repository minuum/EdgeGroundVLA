## 3. 세션 중 발생한 운영 이슈 (데이터 품질에는 영향 없음)

- pos4 수집 중 조이스틱 `_joystick_verify_mode`가 UI 탭 진입 시 자동으로
  `verify`로 전환되면서 수동 조이스틱 구동이 이산적으로 바뀐 것을 발견 →
  `collect`로 복귀 후 다시 `verify`로 복귀(L1 추론시작 단축키 유지 위해).
  이 과정에서 잘못된 모드(SYNC 고착)로 수집된 세션 4건은 전부 삭제 처리함
  (`20261029_194409`, `195507`, `195656`, `195800`) — 위 표에는 포함 안 됨.
- 자율주행 루프 모드가 `drive-mode-vfy` 드롭다운 기본값(`SYNC`)에 고착되어
  있던 걸 ASYNC로 재설정(웹 "▶ START DRIVE" 버튼 1회 클릭 필요) — 이후
  `drive_loop_mode: "ASYNC"`로 정상 기록됨을 h5 attrs로 확인.
- **시스템 전체 행(hang) 1회 발생**: 대시보드(7800)·ROS 응답 전부 끊겨
  로봇이 정지하지 않는 상황 → 운영자가 하드웨어 강제 종료로 직접 정지시킴.
  재부팅 후 서버/대시보드/카메라 프로세스 전부 재기동, `drive/status:
  running=false`, `joystick/mode: collect` 기본값 확인 후 안전 상태로
  복귀했음을 확인. 정확한 행 원인(OOM/열/드라이버)은 로그가 재부팅으로
  유실돼 단정 못 함 — 재발 시 참고용으로 기록만 남김. 이 인시던트로 손실된
  세션은 없음(사고 전후 세션 번호 연속성 확인됨).
- 10/28 핸드오프에서 보고한 "H5 유실 6건" 같은 패턴은 오늘 96건에서는
