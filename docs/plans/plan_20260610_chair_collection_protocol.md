## 0. 확정된 전제 (CH30 검증 결과)

- **객체:** 의자 (색 무관). 배경 대비 분명 + 등받이/좌판이 통으로 잡히는 형태.
- **프롬프트:** `detect chair` (색 수식어 제거, `stool` 단어 금지 — PG2 45%밖에 못 잡음).
- **액션 공간:** V5 8-class 유지 (STOP / FWD / L / R / FWD+L / FWD+R / ROT_L / ROT_R).

## 1. 규모 & 분포 (사용자 결정 6/10, 시간 제약 반영)

- **총 350~500 ep** (PRETRAINED_OBJECT_REPLACEMENT_PLAN 원안)
- **쿼터 관리 없음**: 에피소드는 어차피 모두 개별 수집되므로, 버킷별 정확한 비율을 맞추지 않는다.
  - 진입 방향(Left/Straight/Right)을 **대충 고르게** 섞고, 일부에 복원(탈선→복귀)을 자연스럽게 포함.
  - 33/33/33이나 70/30 같은 숫자는 **목표가 아닌 가이드라인** — 멈춰서 카운팅하지 말 것.
  - 우선순위: **속도 > 비율 정밀도**. 다양성만 확보되면 분포는 사후 분석으로 확인.

### 1.1 수집 가이드라인 (강제 아님)

- 매 에피소드 시작 위치/각도를 의식적으로 바꿔 한쪽으로 쏠리지 않게.
- 가끔(체감 1/3 정도) chair를 프레임 좌/우로 흘렸다가 반대로 꺾어 중앙 복귀 — covariate shift 방지.
- 수집 후 `cx` 분포를 한 번 찍어보고 심하게 쏠렸으면 그때만 보충.

## 2. 수집 0순위 — 로봇 POV chair 검증

> CH30 한계: 스톡 이미지는 근접샷. 본 수집 **시작 전**, 로봇 카메라로 의자 프레임 ~20장 찍어 `detect chair` 실측.
> hit율/cx_std가 스톡과 크게 다르면(저각·원거리에서 붕괴) → 의자 배치/조명 재조정 후 수집 개시.

## 3. STOP 자동 합성 — 의자 기준 재측정 필요

기존 V5(basket): `area_det > 0.65 & cy_det > 0.50` → 도착 직전 3~5프레임 STOP 치환.

⚠️ basket과 의자는 형태/높이가 달라 임계값 그대로 쓰면 안 됨. **0순위 검증 20장에서 도착 시점 의자 bbox의 area/cy 분포를 측정해 임계값 재설정.**

## 4. 시간축 정합 (기존 유지)

- Action-Image Lag 보정: 관측 $s_t$ ↔ $a_{t+1}$(100ms 뒤 조이스틱) 매핑.
- 10Hz 연속 비동기 수집.

## 5. 실패 케이스 배제 (기존 §3.3 유지)

| 유형 | 판정 | 조치 |
|---|---|---|
| `collision_fail` | 의자 충돌까지 미정지 | 전면 30~45cm 정지 후 종료 |
| `forward_collapse` | 탈선 중 chair가 FoV 이탈 | `has_bbox=0` 3프레임↑ → 폐기 |
| `mid_stop` | 주행 중 0.1s↑ 멈칫 | 속도 임계 필터 / 직전 속도 덮어쓰기 |
| `overshoot_fail` | FPE > 0.15m | TLD∈[0.9,1.1] 정렬까지 미세조정 |

## 6. 조명/각도 다양성 (기존 §2.3 유지)

- 조명: 형광등 / 저조도 / 자연광 = 7:2:1
- 각도: 33/33/33에 흡수 (정면/좌30/우30)

## 7. 수정/생성 파일 (수집 단계)

| 파일 | 작업 |
|---|---|
| `scripts/...joystick_data_collector...` | 점검 — 객체명/STOP 임계값 의자용 파라미터화 |
| 데이터 저장 경로 | `ROS_action/mobile_vla_chair_v6/` (신규, V5와 분리) |
| STOP 합성 후처리 | area/cy 임계값을 0순위 측정값으로 갱신 |

## 8. 실착수 전 필요한 것 (최소)

시간 제약상 의사결정은 최소화하고, 막는 것만 해결:

- [ ] **의자 실물 1개** — 색 무관, 배경 대비 분명. 연구실 보유분이면 즉시.
- [ ] **수집 장비** — 평소 쓰던 로봇/조이스틱 그대로. (장비 선택에 시간 쓰지 않음)
- [ ] **0순위 로봇 POV 검증 20장** — exp64 완료 후 GPU 여유 생기면. STOP 임계값도 여기서 같이 측정.

> 위 3개만 되면 바로 수집 개시. 분포·비율은 수집하면서 사후 확인.
