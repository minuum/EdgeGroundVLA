E 종합 — 어떤 factor가 진짜 핵심인가

  1. 그라운딩 품질 — 가장 강한 단일 factor. has_bbox 유무로 오류율 3~5배 차이(CH41).
  2. hidden state 차원 — 2304차원 원시값은 오히려 해롭고, 32차원으로 줄이면 baseline을 넘김(CH43-1).
  3. head 구조 — FC가 근소 우위지만 차원축소보다 영향이 작음(CH43-2).
  4. 텍스트 명령(prompt) — 거의 영향 없음, 이미지 신호가 항상 압도(CH42).
