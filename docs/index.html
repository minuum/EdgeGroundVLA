Current Public Reading

MoNaVLA는 모바일 로봇 내비게이션을 위한 vision-language-action 연구 트랙입니다. E2E VLA(Exp11, CL 0%) 대비 decomposition 접근(CL 96.6%)이 압도적으로 우월함을 확인했습니다. 핵심 발견: grounding 품질(cx 소스)이 아닌 학습 파이프라인(L2-norm + bbox 증강)이 유일한 성능 결정 요소입니다. base PG2 / exp59 LoRA / HSV cx 모두 올바른 파이프라인에서 동일한 96.6%에 수렴 — grounding LoRA 개선은 action 성능에 기여하지 않습니다(확정, 2026-06-12).

Current Technical Interpretation

  • Decomposition 96.6% CL — E2E 0% 대비 압도적 우위 (2026-06-12 확정)
    Exp54/66/67: CLIP + BBox MLP + L2-norm + aug → 96.6% vs Exp11 E2E 0%. 벤치마크: V5 150ep, 29ep val.
  • 파이프라인(L2-norm + bbox 증강)이 유일한 성능 결정 요소
    Simple MLP(exp65b) 10.3% vs L2+aug(exp66) 96.6% — 동일 cx 소스에서 파이프라인만 바꿔 ×9.4배. grounding 품질(cx 소스)은 무관.
  • cx 소스 무관성 확정 — LoRA grounding 개선이 action에 기여하지 않음
    HSV(exp54) = base PG2(exp66) = exp59 LoRA(exp67) = 96.6%. grounding LoRA 연구의 action 기여 = 0 (음성 결과).
  • Text attention 구조적 사망 — Google-robot backbone 기인
    Exp11/15 모두 text attention 0.000%. LoRA/head-only 모두 복구 불가. Pure HF Kosmos-2는 정상(22.6%). E2E 실패의 근본 원인.
  • 다음 단계: chair 객체 데이터 수집 (좌/우 0개 → 목표 150ep)
    파이프라인 스크립트 완비. 수집 완료 후 즉시 학습 → CL 평가. 파일럿(31ep 중앙만): 57.1% (데이터 편향 기인).
