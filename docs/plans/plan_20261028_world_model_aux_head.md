# 계획: 미래 예측(월드 모델식) 보조 손실로 bbox 반응성 높이기 (구현 승인 전)

## 0. 풀려는 문제
- 현재 EGVLA2는 행동을 **bbox 없이 이미지 평균에 맞춰** 출력한다: 반사실 민감도 S ≈ −0.7°(타깃 cx ±0.2 이동에 방향 변화 1° 미만), 실기 raw 방향 ≈ −48° 고정(cx와 Spearman −0.07).
- 지금까지의 해결(서보 라벨 E1b 등)은 **정답 라벨을 바꿔서** S를 올렸고, 그 대가로 사람 방향 오차가 +9~22° 늘었다(맞교환).
- 이 계획은 **라벨을 바꾸지 않고** 모델이 "내가 이렇게 움직이면 타깃이 화면에서 어디로 가는가"를 예측하도록 보조 과제를 붙여, 같은 라벨로 타깃 위치와 행동의 연결을 학습시킬 수 있는지 본다.
- **가설(검증 대상, 확정 아님)**: 보조 예측을 풀려면 특징·bbox 위치 정보를 내부 표현에 담아야 하므로 행동 헤드도 그것을 쓰게 된다. 반대로 보조 손실이 행동 출력에 영향 없이 표현의 한쪽에서만 풀릴 수도 있다 — 그래서 중단 기준을 둔다(§5).

## 1. 접근 (월드 모델 = 잠재 공간 미래 예측, 픽셀 생성 없음)
데이터: 에피소드 300개·29,161프레임의 연속 프레임별 `bbox`(창 3×4=12-d, 마지막 4개가 현재 프레임), 융합 특징 `feat`(768-d), 행동 청크 `chunk`(H=8). 모두 이미 캐시(`S1.load_main()`, `T.CACHE`)에 있어 **새 특징 추출이 필요 없다**.

보조 과제(훈련 때만):
- 입력: 행동 스트림 표현 h(블록 통과 후 평균) + 실제 행동 청크의 임베딩(teacher forcing)
- 목표 (k 프레임 뒤, k ∈ {4, 8}; 사람 행동이 영상보다 약 2프레임 앞서는 지연을 고려):
  - **Δbbox** = bbox_{t+k}(cx, cy, w, h) − bbox_t (L1)
  - **Δfeat** = feat_{t+k} − feat_t (코사인 손실)
- 에피소드 끝 k 프레임, 타깃 소실(bbox 없음) 프레임은 마스크.
- 총 손실 = flow 행동 손실 + λ_w · 보조 손실. 추론·배포에는 보조 헤드가 **없다**(지연·체크포인트 호환 변화 없음).

왜 Δ(변화량)인가: 미래 bbox를 그대로 예측하면 "현재 bbox를 복사"로 풀려 정보가 없다. 변화량은 행동에 의존하므로, 모델이 "행동 ↔ 화면상 타깃 이동" 관계를 배워야 줄어든다.

## 2. 비교 조건
공통: 기존과 동일(FM-π0 층2·폭128, 서브골 드롭아웃 30%, 120 epoch, 분할 fold0·lopo_center·lopo_strong_right, actions_exec 라벨, 같은 seed 규칙).

| 이름 | 보조 목표 | 용도 |
|---|---|---|
| W0 | 없음 | 대조(같은 코드 경로·seed로 재학습 — 기존 수치와 구현 차이를 배제) |
| W1 | Δbbox만 (k=4) | 가장 직접적인 위치 과제 |
| W2 | Δfeat만 (k=4) | 시각 변화 과제(JEPA식) |
| W3 | Δbbox + Δfeat (k=4) | 결합 |
| W3k8 | W3, k=8 | 예측 거리 영향 |
| (선택) W3-prefix | W3이되 h 대신 prefix(bbox·특징 선형 투영)에서 예측 | 기울기가 블록을 거치지 않을 때의 대조(보조 손실이 행동 경로를 통하는지 확인) |

λ_w 기본 0.3 (W1~W3 결과로 {0.1, 0.3, 1.0} 확인은 2단계에서).

## 3. 변경 파일 (승인 후)
- **신규** `robovlm_nav/models/egvla2_fm_wm.py`: `PiZeroFMWM(PiZeroFM)` — 기존 `egvla2_fm_heads.py`는 **수정하지 않음**. 보조 MLP는 별도 모듈로, state_dict에서 `aux.*`만 분리 저장하면 기존 `PiZeroFM`에 `strict=False`로 로드 가능.
- **신규** `scripts/gap_wm.py`: `gap_e1b.py`의 분할·평가 틀(`GS.split_metrics`, `live_inputs`)을 재사용. 프레임별 (t, t+k) 쌍 생성은 `S1.load_main()`의 에피소드 순서에서 인덱싱.
- 출력: `docs/v5/egvla2_fm/gap_wm.json`. 로그: `runs/e2e_cache/logs/gap_wm.log`(/tmp 금지).
- 코드 스케치:
```python
class PiZeroFMWM(PiZeroFM):
    def __init__(s, bdim, fdim, aux_dim=4+768, **kw):
        super().__init__(bdim, fdim, **kw)
        s.aux = nn.Sequential(nn.Linear(HID + ADIM * H, 256), nn.GELU(), nn.Linear(256, aux_dim))
    def forward(s, bbox, feat, xt, t, a_true=None):
        prefix = torch.stack([s.sub(bbox), s.vis(feat)], 1)
        h, c = s.inp(xt) + s.pos, s.tm(temb(t))
        for blk in s.blocks: h = blk(h, prefix, c)
        out = s.out(h)
        if a_true is None: return out
        z = torch.cat([h.mean(1), a_true.flatten(1)], -1)
        return out, s.aux(z)
```
기존 서버·정책 코드(`egvla2_fm_policy.py` 등)는 건드리지 않는다.

## 4. 평가 (기존 간극 지표 그대로 + 보조 진단)
1. **S, S_img**(반사실 민감도), 방향 오차, 회전 재현율, 엣지 프레임 방향 오차, 실기 416프레임 규칙 전문가 일치(회귀 확인용; 규칙 라벨과 순환이므로 단독 근거로 쓰지 않음)
2. **보조 진단**: 안 본 에피소드에서 "Δ=0 복사" 기준 대비 Δbbox 예측 오차 — 이것이 개선 없이는 모델이 변화를 못 배운 것이므로 S 변화의 해석이 불가
3. 3분할 평균과 분할별 값을 함께 표시(분할 간 편차가 크므로 평균만 쓰지 않음)

## 5. 성공·중단 기준 (결과 보기 전에 고정)
- **1단계**(seed 1, W0·W1·W2·W3·W3k8 × 3분할): W0 대비 **S가 +5° 이상 오르고 방향 오차 증가 ≤ 3°**인 조건이 하나라도 있으면 2단계로. W0 대비 S 변화가 +3° 미만이면 **중단하고 "보조 손실로는 bbox 반응이 생기지 않음"으로 기록**.
- **2단계**(최선 조건 × λ_w {0.1, 0.3, 1.0} × seed 3): 평균의 표준편차 밖에서 개선이 재현될 때만 채택 후보. 서보 라벨(E1b)과 결합 가능성은 그 후에 별도 검토.
- 비교 대상 맞교환 기준: 서보 라벨 λ=0.5는 S +3.0° / 방향 +9° — 이보다 **S는 같거나 높고 방향 증가가 작아야** 의미가 있다.
- 채택되더라도 실기 폐루프 효과는 별도 검증 전까지 주장하지 않는다(오프라인 지표는 수단).

## 6. 비용·일정

- 1단계: 5조건 × 3분할 ≈ 75~90분. 2단계: 3 λ × 3 seed × 3분할 ≈ 1.5~2시간.
- **GPU 경합**: 전 단계 E2E가 05:35쯤 종료 예정이므로 종료 후 시작. 풀링 비교 실험과 번갈아 실행.

## 7. 트레이드오프·위험
- 보조 헤드가 훈련 분포(사람 데이터)의 행동-이동 상관만 배우고 S에는 효과가 없을 수 있다(가장 가능성 있는 실패). → §5 중단 기준과 W3-prefix 대조로 판별.
- 사람 행동이 영상보다 앞서고 실기 SYNC는 지연 0이라 학습한 동역학이 실기에서 어긋날 수 있다. 이 계획은 오프라인 가설 검증까지만 다룬다.
- Δfeat는 융합 특징 공간의 변화이므로 조명·움직임 번짐이 섞인다. W1(Δbbox)이 더 직접적이라 비교 조건으로 분리했다.
- 서빙에 영향이 없고 기존 코드 수정이 없어 되돌리기 쉽다(신규 파일만 삭제).
