## 1. 왜 하나 (리서치로 확인한 사실)
출처: `docs/v5/egvla2_fm/t7_all_seeds.json` (452 A3 세션 5,845프레임 재생, 시드 10개, 기준은 A3의 명령).

| 종류 | 각도 차(정상) | 박스 반전 좌우 일치 (평균, 최소~최대) | 없는 문구 정지 | 동의 문구 정지 |
|:--|:--|:--|:--|:--|
| V0 | 3.9° | 10% (7~12) | – | – |
| V0R (V0 + 박스 오류 증강) | 6.9° | 75% (67~79) | – | – |
| V4 | 2.8° | 86% (**42**~94) | 99% | 6% |

- V4는 정상 상황에서 A3와 가장 가깝고 없는 문구에서 거의 다 멈추지만, **박스 반전에서 시드에 따라 42~94%로 흔들린다.**
- V0R은 같은 증강으로 반전 일치를 10%에서 75%로 올렸지만 정상 상황의 각도 차가 3.9°에서 6.9°로 늘었다. 즉 증강은 반전에 도움이 되지만 정상 정확도를 잃는다.
- **미확인:** 이 증강을 V4(문구 입력 모델)에 붙이면 흔들림만 줄고 정상 정확도는 유지되는지, 아니면 V0R처럼 정상 정확도를 잃는지는 아직 모른다. 이것이 이번 실험의 질문이다.

## 2. 접근
V4의 학습 레시피(`scripts/eval_text_cond_t4.py` `fit`, 변형 "V4")에서 **정상 문구(positive) 샘플의 박스 처리만** V0R(`scripts/eval_bbox_robustness.py` `fit_robust`)의 증강으로 바꾼다. 나머지는 V4와 같다.

| 항목 | V4 (현재) | V4R (제안) |
|:--|:--|:--|
| 정상 문구 샘플의 박스 | 30% 확률로 전부 0 | 제거 30% / 흔들기(jitter) 20% / 좌우 반전 10% / 그대로 40% (V0R과 동일) |
| 정답(서보 라벨) | 훼손 전 박스 기준 | 훼손 전 박스 기준 (V0R과 동일) |
| 없는 문구 샘플 | 정지 라벨, 박스는 `KEEP`=0.5 확률로 유지 | **변경 없음** |
| 문구·어휘·헤드·에폭(120)·stride(9)·데이터(300에피소드) | – | 변경 없음 |

변경은 한 가지(정상 샘플의 박스 증강)라서, 결과가 달라지면 원인을 그 한 가지로 좁힐 수 있다.

### 코드 스니펫 (신규 파일 `scripts/t7_train_v4r.py` 안에서만, 기존 파일은 수정하지 않음)
```python
# eval_text_cond_t4.fit 의 positive 박스 처리 한 줄을 교체한 복사본
u = torch.rand(B, 1, device=DEV, generator=g)
bb_pos = torch.where(u < 0.3, torch.zeros_like(bb0),
          torch.where((u >= 0.3) & (u < 0.5), RB.corrupt(bb0, "jitter", g),
          torch.where((u >= 0.5) & (u < 0.6), RB.corrupt(bb0, "wrong", g), bb0)))
bb = bb_pos                                   # V4는 여기가 bb0 * (rand > 0.3)
# 이후 neg 샘플 처리(bb = where(neg, bb0 * keep, bb))는 V4와 동일
```

## 4. 평가
기존과 같은 지표·같은 452세션·같은 A3 캐시(`runs/egvla2_fm/t7_a3_cache.npz`)를 쓴다: 각도 차, 좌우 일치(정상·반전), 반전 각도 차, 없는 문구 정지율, 동의 문구 정지율. 모두 시드 10개 평균(최소~최대).

### 성공 기준 (제안 — 승인 때 사용자가 확정하거나 고쳐 주세요)
실험을 돌리기 전에 정해 두어야 결과를 보고 기준을 바꾸는 일이 없다.

| 기준 | 값 | 근거 |
|:--|:--|:--|
| ① 반전 좌우 일치의 **시드 최소값** | ≥ 70% (V4는 42%) | V0R의 최소값이 67%, 평균이 75%라 그 수준 이상이면 흔들림이 줄었다고 본다 |
| ② 정상 각도 차(평균) | ≤ 3.5° | V4 2.8°보다 0.7° 이내로 악화까지 허용. V0R(6.9°)처럼 크게 잃으면 실패 |
| ③ 없는 문구 정지(평균) | ≥ 95% | V4 99% 대비 유지 |
| ④ 동의 문구 정지(평균) | ≤ 10% | V4 6% 대비 유지 |

- ①~④가 모두 충족되면 "V4R이 V4보다 낫다"고 쓴다.
- ①만 충족하고 ②가 깨지면 "V0R과 같은 정상 정확도 손실이 V4에도 생긴다"고 쓴다.
- 어느 쪽이든 결과를 그대로 보고한다.

## 5. 트레이드오프·위험
- **정상 정확도 손실:** V0R에서 이미 나타났다. V4R에서도 생길 수 있다(성공 기준 ②가 이를 잡는다).
- **증강 강도 하나만 시험:** V0R과 같은 강도(30/20/10%)만 쓴다. 더 약한 강도(예: 반전 5%)는 이 계획에 넣지 않았다. 필요하면 두 번째 팔로 추가할 수 있다(시간 +40분 정도).
- **시드 10개는 같은 300에피소드로 학습:** 초기값·순서 편차만 반영하고 데이터 분산은 반영하지 못한다. 데이터 분산은 별도 실험(위치 제외 학습)이 필요하다.
- **기준이 A3와의 유사도:** A3가 정답이라는 보장은 없고, 실기 성공을 예측하지 못한다. V4R도 실기 검증은 없다.
- **이름·번호:** `V4R`, `EG4-07`은 **제가 제안한 이름**이다. 사용자가 확정하지 않았다.
