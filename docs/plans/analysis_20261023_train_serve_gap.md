# 분석: 학습–서빙(실기) 간극 — 전처리는 같고, 장면·물체 분포가 다르다 (2026-10-23)

로봇 세션 질문 3가지에 대한 답: (1) raw(chunk_first) vs 최종(action) 평탄함의 원인, (2) 학습 특징 vs 라이브 특징 직접 비교, (3) 다음 실험.

## 1. 서빙 전처리는 학습과 동등하다
실기 세션 프레임(434장)을 학습 때와 같은 Florence-2 추출기(fp32, JPEG q95 왕복)로 다시 계산했더니 **서버가 기록한 bbox와 소수점 셋째 자리까지 같다**(예: cx 0.758, cy 0.604, area 0.026). 서버 경로·JPEG·dtype 어느 쪽도 간극의 원인이 아니다.

## 2. 그런데 입력 분포는 학습과 다르다 (covariate shift)
| 지표 | 학습(보류 에피소드끼리) | 실기 세션 |
|---|---|---|
| 학습 특징 최근접 코사인(평균 / p10) | 0.9974 / 0.9954 | **0.9939 / 0.9885** |
| 최근접 코사인 중앙값 | 0.9980 | 0.9953 (≈ 학습의 p10 수준) |
| 특징 중심 코사인 | 0.9759 | 0.9671 |
| bbox 검출률 | 99.96% | **89.9%** (10%가 화면 이탈·가림) |
| bbox 면적 중앙값 | 0.059 | **0.034**(타깃이 더 멀리, 접근이 덜 됨) |
| 타깃 cx 평균 | 0.483 | 0.574 |
→ 실기 프레임의 중앙값 유사도가 학습 보류 에피소드의 하위 10%와 같다. 절대 차이는 작아 보이지만(풀링 특징이라 공통 성분이 큼) 분포 이동은 분명하다.

## 3. 눈으로 본 차이 (그림: `docs/v5/egvla2_fm/figures/compare_train_live_20261022.png`, 위=학습, 아래=실기)
- **바구니 색**: 학습 바구니 중심 패치 RGB (122, 117, 112) R−B=+10.6(베이지), 실기 (107, 110, 111) R−B=−4.2(청회색). 같은 'gray basket' 프롬프트로 검출은 되지만 **물체 외형이 다르다**(색·크기·형태).
- **배경**: 실기 프레임에는 오른쪽에 흰 패널 벽과 책상·장비가 보임(학습 프레임은 평평한 흰 벽과 바닥뿐). 타깃이 가까워질수록 이 방해물이 시야에 들어온다.
- 전체 평균 색(학습 B/R 1.046 vs 실기 0.945)은 배경 조명 차이도 시사.

## 4. 로봇 세션의 가설 점검: "EMA가 반응성을 죽인다"
DRIVE 324스텝의 모델 raw 방향각(atan2(ly,lx)): 평균 −35°, 중앙값 **−48°**, 분위 10/90 = −56°/+40°. **cx와의 Spearman −0.07**(cx 구간별 평균각 −21~−41°). 즉 raw 자체가 타깃 위치와 무관하게 거의 같은 대각선(전진+좌 strafe)이다. 최종 action이 평탄한 이유는 EMA가 아니라 **단위 방향 정규화(크기 정보 폐기)·gain 1.15·속도 0.7 고정**이라는 설계 때문이고, EMA를 꺼도 방향각은 거의 안 바뀐다(EMA off 재시험은 싸지만 우선순위 낮음).
이는 CH77의 오프라인 결과(방향이 bbox cx보다 경로 의도에 의해 결정, Spearman ≈ −0.07~−0.21)와 일치한다: **모델은 타깃 서보가 아니라 경로 의도를 재생한다.**

## 5. 시사점·다음 액션

3. **서보 항**(cx 피드백 strafe 보정)과 비례 회전은 모델 외부 규칙으로 별도 비교군(분석 문서 `analysis_20261023_rotation_physical_motion.md`).
