## 0. 최종 목표와 판정 기준
- **논문 주장(목표)**: 단일 비전 백본(Florence-2) + 경량 연속 액션 헤드로 **지연을 크게 줄이면서(젯슨 fp32 2.41×) 실기 성공률을 EGVLA1(92.0%, 276/300)과 동등 이상**으로 유지하고, 그라운딩 결측에 견고하다. 2026-07-23 미팅의 "경량화(Raspberry Pi 탑재 가능성)" 방향과 같은 축.
- **판정 기준**: (1) 폐루프 300회(3 시작 위치 × 5 목표 위치 × 20) SR — EGVLA1과 시작 위치별 비교, (2) 충돌·개입·소요 시간, (3) 젯슨 지연·메모리(가능하면 전력), (4) 오프라인 지표는 보조.

## 2. P1 결정 항목 (실기 전에 정해야 함)
| 결정 | 선택지 | 근거 / 필요한 정보 |
|---|---|---|
| 시작 구간 서빙 방식 | (a) K=8 평균+EMA(현재) / (b) 샘플 군집 후 하나를 골라 유지 / (c) 경로를 조건으로 입력 | 시작 10% 프레임의 47%에서 샘플이 45° 이상 갈림(⑥-13). **장애물이 경로 사이에 있으면 평균(≈직진)이 위험** → `obstacle_layout_type=hori`의 실제 배치 확인 필요 |
| 헤드 | FM-π0(권장) / MLP 회귀를 실기 비교군으로 일부 포함 | 정확도 동급, 회귀가 더 부드럽고 빠름. 비교군은 예: pos1 × 5 목표 위치 × 4회 = 20회 |
| 체크포인트 | 현 배포(C+드롭아웃30, 120ep) / 반전 증강 재학습본 | P0 반전 증강 결과로 결정 |
| dtype | fp32(공정 비교) / fp16(지연 약 절반, 방향 영향 0.03°) | 실기 본 시험은 fp16도 후보. 비교용 지연은 fp32로 따로 기록 |
| 구동 경로 | 단계 A 하이브리드(기존 STOP·ROT 규칙 + 연속 방향) / 단계 B 단독 서버 | 첫 구동은 A, 본 평가는 B 권장(지연·구성 비교가 깔끔). B의 정지·소실·평활 값은 드라이런 로그로 |
| 평활 | K=8, EMA 0.5 | 오프라인 스윕(저크 사람 수준, 지연 ≤2프레임) |

## 3. P3 모델 개선 트랙 (우선순위)
1. ~~좌우 반전 증강~~ **기각(2026-10-21)**: 안 본 목표 위치 평균 16.48→17.10°(10쌍 중 7쌍 악화). CH77 ⑥-15.
2. **경로 모호성 처리**: 샘플 군집·모드 선택, 선택 유지(commitment) 규칙, 또는 경로 조건 입력(레포 V6 실험에서 경로 정보 +1.1~1.6%p). 오프라인 방향 오차로는 판정 불가 → 폐루프 성공·충돌로 판단.
3. **시간 맥락**: 직전 실행 액션 또는 이전 특징 이력 입력(인과 혼동 위험 → ablation).
4. **통제 실험(논문 근거)**: MLP 회귀를 S1과 같은 5-fold×5 seed로, 파라미터 수를 맞춘 비교, 같은 Florence-2 특징의 이산 8-class 헤드 학습(액션 표현 효과 직접 대조).
5. **데이터**: pos2·pos3 시작 위치 수집 확대, 다른 장소·조명, 속력 가이드 적용 후 재수집(속력 학습 가능성).

## 4. P4 경량화 트랙 (논문 방향과 직결)
1. **fp16 서빙**: 젯슨 Florence-2 821ms → 벤치 기준 약 372ms 예상. 실측 필요.
2. **Florence-2 디코딩 비용**: 현재 그라운딩 생성(beam 3, 최대 128토큰)이 지연의 대부분일 가능성 → beam 1·토큰 수 축소의 정확도·지연 trade-off 측정.
3. **양자화·변환**: int8(가중치), ONNX/TensorRT 경로 검토(정확도 영향 측정 필수).
4. **Raspberry Pi 가능성**: Florence-2 base(231M)의 CPU 지연 측정 → 불가하면 소형 검출기 증류 등 후속 연구로.
5. **자원 지표**: 메모리·전력(젯슨), EGVLA1 대비 표.
