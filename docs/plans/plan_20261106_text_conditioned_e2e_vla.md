# plan: 텍스트가 행동에 직접 들어가는 E2E VLA (EGVLA2-T) — 2026-11-06

> 상태: **초안(승인 대기, 코드 미작성).** 오프라인 점검 결과(`docs/v5/egvla2_fm/text_robustness.json`)가 나오면 §2를 확정한다.

## 0. 왜 하는가
- 교수님(11/05) 질문: 지시문을 바꾸거나 물체를 바꿔도 가는가 = "VLM이 일반화를 해주는가, 우리 학습이 한 건가".
- 사용자 방향: "진짜 E2E VLA(텍스트가 행동까지 직접 영향)로 가는 게 맞다."
- 지금(EGVLA2) 구조: `텍스트 → Florence-2 디코더 → bbox` + `이미지 풀링 768-d(텍스트 무관)` → 헤드. 텍스트는 bbox 한 경로로만 작용(코드: `precompute_v6_florence2_fused.run_batch`, 풀링은 `img_feats.mean`이라 인코더 융합 이전 값).

## 1. 진단: 지금 학습으로는 왜 텍스트가 안 쓰이나
1. 학습 300에피소드 모두 문구가 `gray basket` 하나 → 텍스트를 입력으로 줘도 상수라 **쓸 이유(그래디언트)가 없다**. 헤드가 텍스트를 무시하는 지름길이 최적이다.
2. 과거 교훈(메모리): Kosmos V5 Exp17~41C에서 text attention 0% — 텍스트 경로는 데이터에 텍스트 변동이 없으면 구조를 바꿔도 죽는다. 같은 함정을 피해야 한다.
3. 따라서 "구조만 바꾸기"로는 불충분. **텍스트에 따라 정답이 달라지는 학습 신호**가 필수다.

## 2. 접근(단계별, 앞 단계가 실패하면 중단)
### 단계 T0 — 텍스트 민감도 측정(학습 없음, 오프라인 점검과 함께)
- 지금 파이프라인의 텍스트 효과 = bbox 변화뿐임을 수치화: 문구 변형별 검출률/Δcx/Δ명령(`eval_text_robustness.py`, 진행 중).
- 추가: Florence-2 **인코더 융합 은닉**(image+text 토큰, `language_model.get_encoder()` 출력)을 풀링했을 때 문구 변화에 얼마나 변하는지(cos). 텍스트가 특징에 실리는지 확인.

### 단계 T1 — 텍스트 융합 특징으로 헤드 입력 교체 (구조 변경, 데이터 불변)
- `feat768`(이미지 전용) → `feat_fused`(융합 인코더 은닉 풀링, 같은 768-d) 또는 두 개 이어붙임. 재캐싱 비용: 300ep 전체 1패스(기존 precompute와 동일 규모).
- 기대: 헤드 코드는 `fdim`만 바뀜(`egvla2_fm_heads.py` 무수정 가능). 단 §1-1 때문에 **이것만으로는 텍스트 사용이 학습되지 않음**을 T2에서 검증하는 기준선으로 쓴다(귀무 가설).

### 단계 T2 — 텍스트가 정답을 바꾸는 학습 신호 만들기 (핵심)
세 가지 신호를 섞는다(학습 데이터 재라벨만, 새 수집 없이 가능한 것부터).
1. **패러프레이즈 증강**: 같은 에피소드에 `gray bin / the gray container / go to the gray bin …` 무작위 부여 → 불변성 학습(텍스트를 "이해"해도 같은 행동).
2. **음성 지시(wrong-target) 대조**: 같은 프레임에 `red chair` 등 장면에 없는 물체 문구 → 정답=정지/제자리(서브골 결측 표현과 동일하게 bbox=0). 텍스트가 바뀌면 행동이 바뀌어야만 손실이 줄어드는 최초의 신호.
3. **반사실 대조 손실**: (프레임, 문구)에서 문구만 바꾼 쌍의 행동 차이를 `S`(counterfactual sensitivity, feature-gap 실험의 지표)로 측정·마진 강제.
- 평가: T0의 S 지표 + 교수님 시험 1·2의 오프라인 대응(패러프레이즈 검출 유지, 오답 문구 시 정지율).

### 단계 T3 — 진짜 "텍스트가 목표를 고르는" 데이터(새 수집, 필요 시)
- 장면에 물체 2개(회색 바구니 + 다른 물체) 두고, 문구가 가리키는 쪽으로 가는 조이스틱 시연 소량(예: 문구당 20ep). 기존 CH61류 수집 절차 재사용.
- 이 단계 없이는 "물체 단어로 목표를 선택"하는 E2E를 주장할 수 없다. T2까지는 불변성·거절만 보인다.

### 대안/비교군 (정직한 대조)
- **모듈형 유지(현재)**: 텍스트→bbox(오픈 어휘 VLM)→헤드. 교수님 시험 2(물체 교체)는 이미 이 구조로 가능성이 높음(헤드는 "bbox로 간다"만 배움). E2E의 이득이 무엇인지(예: bbox가 못 잡는 개념 지시)를 T2 결과로 보여야 정당화된다.
- 증류: 모듈형(teacher)이 라벨 → 학생 E2E. 새 수집 없이 가능하나 학생은 teacher 상한. 이득은 지연/단일 모델화뿐.

## 4. 성공 기준(사전 선언)
- T1: 문구 변경 시 융합 특징 cos < 0.99 (텍스트가 특징에 실림) — 아니면 T1 폐기.
- T2: (a) 패러프레이즈 5종에서 방향 오차 ≤ 기준 +1°, (b) 오답 문구 정지율 ≥ 90%, (c) 기존 A3 대비 오프라인 방향 오차 악화 ≤ 1°. 단일 시드이므로 3-split 평균과 시드 3개로 보고.
- 어느 것도 **오프라인 지표는 폐루프 성공을 예측하지 못한다**(CH79 결론). 실기 확인은 각 5~10회 짧게.

## 5. 위험
- 텍스트 지름길(§1) 재현 → T2 신호 없이는 무효.
- 오답 문구에 Florence-2가 엉뚱한 bbox를 내면(오검출) 음성 신호의 라벨이 오염 — T0 결과로 사전 확인.
- Jetson 지연: 융합 은닉 풀링은 인코더가 이미 계산한 값이라 추가 비용 거의 없음(확인 필요).

3. 실기 시험 물체 종류(로봇 쪽과 협의).
