# 교수님 진행 보고 — EdgeGround-VLA 2 (EGVLA2) 현황 (2026-10-23)

## 0. 한 줄 요약
Florence-2 단일 백본 + 경량 연속 액션 헤드(EGVLA2)를 실기에 올려 첫 폐루프 드라이런(10/22, 유효 16세션)을 했고, **오프라인 지표는 양호하지만 실기에서는 모델이 타깃 위치에 반응하지 않아 이탈**하는 것을 확인했다. 서빙 버그 3건(시작 회전 누락·회전 부호·설정 차이)은 수정했고, 이탈 원인(서보 부재)을 메우는 학습·규칙 후보를 시험 중이다. **실기 성공률(300회 폐루프)은 아직 측정 전**이며 EGVLA1 기준선은 92.0%(276/300)다.

## 1. 목표와 현재 위치
| 항목 | 내용 |
|---|---|
| 목표 | OWLv2+Kosmos-2(EGVLA1)를 Florence-2 1개로 단일화하고 연속 액션을 내는 경량 헤드로 실기 성공률을 EGVLA1과 동등하게 유지하며 지연·자원을 줄임(경량화 방향) |
| 지연 | 젯슨 fp32 백본 1971→817ms(2.41×), 서버 왕복 약 0.89초(지연의 94%가 Florence-2 그라운딩) |
| 데이터 | pos1 시작, 15셀(목표 위치 5 × 경로 3) × 20 = 300 에피소드·29,161프레임, 조이스틱 연속 수집 |
| 현 단계 | 오프라인 학습·평가 완료 → 실기 폐루프 사전 점검(드라이런) → 간극 보정 학습 |

## 3. 실기 폐루프 드라이런에서 새로 발견한 것
| # | 발견 | 근거 | 조치 |

| 2 | 회전 부호 반대 | 실기 확인: 이 로봇 +az=우회전(학습 기록과 같음) | 부호 정정, 타깃 cx로 방향 결정 |
| 3 | **모델이 타깃 위치를 안 씀** | 반사실 민감도 S −0.7°(cx ±0.2에 방향 1° 미만), raw 방향 −48° 고정(cx와 Spearman −0.07), 실기 10/17 세션 소실 | 외부 서보(구현, 기본 끔), 서보 라벨 학습(시험 중) |

| 6 | 전처리는 동일, 입력 분포 이동은 작음 | 서버 bbox와 재계산 bbox 일치, 특징 최근접 코사인 0.9937 vs 0.9974 | 바닥·조명 증강 시험 |
| 7 | 순서 정렬 정상, 단 학습에서 사람 명령이 영상보다 약 2프레임(0.26초) 앞섬 | bbox·특징 오프셋 0 일치, 액션–영상 상관 최대 지연 k=−2 | 입력 시간 구조 차이 가설(미측정) |

## 5. 논문 관점의 정리(초안)
- **주 서사**: 단일 백본 경량화로 지연 2.4배 감소(지연·자원 표) + 연속 제어.
- **정직한 분석(보조)**: FM·서브골은 오프라인 방향 정확도 이득이 없고, 오프라인 방향 오차는 폐루프 성공을 예측하지 못한다 → **타깃 반응성(반사실 민감도)** 같은 새 지표와 데이터·라벨 설계(서보형)가 필요.
- 명시할 한계: 실기 성공률 미측정, 단일 장소·pos1 학습, 드라이런 세션에 성공 판정 없음.

## 6. 교수님께 여쭙고 싶은 점
1. 타깃 서보(외부 규칙 vs 서보 라벨 학습)를 논문의 주 기여로 둘지, 한계 분석으로 둘지.
2. 평가 지표: 오프라인 방향 오차 대신 폐루프 SR·소실률·소요 시간과 반사실 민감도를 제안해도 되는지.
3. EGVLA3(지시문 조건, 상위 계획 + 하위 제어) 방향과 현재 서보 문제의 우선순위.
4. 인코더 압축(학습 없는 압축, Florence-2 대상) 연구와의 관계·일정.
