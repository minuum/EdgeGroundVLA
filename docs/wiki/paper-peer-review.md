# KCI 논문 심사 대응 (1차/2차/3차 재심)

<p class="tagline">논문 제출 후 받은 심사위원 리뷰를 서술 보강 vs 실제 실험 필요로 분류해 대응한 기록 — 각 라운드의 지적사항, 그에 대한 ablation/재분석 결과, 재심 진행 상황.</p>

<div class="summary-box" markdown="1">

**압축 요약**

1차 심사 결과는 위원1·3 "수정 후 재심", 위원2 "수정 후 게재"다. 9건의 지적을 사람이 결정할
필요 없이 서술만 보강하면 되는 것과 실제 데이터/실험이 필요한 것으로 나눠 대응했다.
서술 보강 6건(lightweight 용어 재정의, 스코프 한계 명시, Mobility VLA 비교 재검토, frozen
인코더 결합 설명, Fig/Table 인덱스 표기, 하이퍼파라미터 서술 확장)은 영문 복붙 문단까지
`revision_briefing.html`에 준비됐다. 실제 데이터가 필요했던 두 건 중 하나(그라운딩 인코더
기여도 ablation)는 배포와 동일 조건에서 돌려 답을 얻었다: OWLv2 bbox 단독 64.09%, Kosmos-2
vision 단독 73.71%, 융합(배포 구성) 73.87%(best seed 74.13%가 배포 체크포인트 저장값과 정확히
일치) — Kosmos-2 비전이 성능 대부분을 담당하고 OWLv2는 보조적이라는 결론이 PG2 기반 이전
실험(Exp14)과 같은 방향으로 재확인됐다. 다른 하나(실패 케이스 원인 분류)는 시도 결과
**데이터가 존재하지 않는다는 것을 확인**했다 — `episode_log.csv`의 "실패" 기록은 95/100
헤드라인 배치가 아니라 그 이전 개발 단계 디버깅 로그였고, 정작 95/100 배치 자체는 H5에
세션별 성공/실패 라벨이 없다. 대신 원인 분해가 가능한 유일한 자료인 89/100 배치의 미검출
프레임 confidence 분포를 출처를 명시하고 인용하는 쪽으로 정직하게 서술하기로 했다. 안전(충돌
회피) 논의는 현재 파이프라인에 없는 기능이므로 Limitation 절에 명시하는 것으로 처리한다.
같은 날 데이터를 다시 파고들어 세 가지를 더 찾았다: ① ablation을 클래스별로 쪼개보니 STOP·
ROT_L·ROT_R은 bbox 단독이 vision 단독보다 훨씬 유리하고(예: ROT_L 100% vs 33.3%), 심지어
fused가 bbox_only보다도 낮게 나온 경우가 있어 — 표본이 작긴 하지만(28프레임) "단순 concat 융합이
희귀 클래스에서 시각 신호에 가려질 수 있다"는 관찰을 얻었다. ② 실기 5개 목표 방향이 Stage 1의
5-class 방향 대조학습 카테고리와 정확히 대응한다는 근거를 찾아 "목표 지점 선정 기준" 질문에
답했다. ③ 가장 중요한 정정: "5개 시작 위치"가 실은 로봇 출발지·카메라·트랙이 전부 동일한 채
타겟 방향만 다른 것이었다는 걸 재확인했고, 그래서 위원1-②/3-①이 요구한 진짜 환경 독립성은
서술로 넘길 수 없고 **실제로 새 실기가 필요**하다고 판단을 바꿨다. 최소 실험 규모(타겟 "중앙" 고정
+ 신규 조건 3개 × n=15~20, 총 45~60회, Wilson CI 하한 70~76%)까지 계산해 제안한 상태이고,
실행 여부는 재심 기한에 달려 있다. 재심 기한이 이번 주(2026-09-14~09-20)로 확인돼, 시간 여유를
감안해 n=20(조건당, 총 60회, Wilson CI 하한 76.4%, 기존 프로토콜과 동일 규격)으로 확정하고
09-15~16 실기 실행 → 09-17 결과정리 → 09-18 논문 반영의 일정까지 잡았다.

재사용, 위치2·3만 신규 실기(각 5방향×n=5, 합계 50회) — 위원1-②/
3-①이 요구한 "학습-테스트 목표 동일성"과 "출발 위치 독립성"을 동시에 다룸.
② 조도 ablation — 기존 위치에서 조도만 바꿔 그리드와
분리된 독립 변수로 진행(5방향×n=10=50회) — 원인 혼동 방지.
③ 시간 변화 — 새 실기 불필요. 학습 데이터(686개 H5) 파일명
타임스탬프를 직접 세어 검증: 심야(00-04시) 26% · 아침(05-10시) 9% ·
점심(11-14시) 4% · 저녁(19-23시) 26%, 오후(15-18시)는 0% — "아침·점심·저녁 수집"이라는
서술은 대체로 맞지만 정확히는 4개 시간대(오후 공백)이므로 논문엔 실측 분포 그대로 인용하기로 함.
④ 카메라 배치 조건 — 범위 제외 확정: 72-1~72-5에서
"확인 필요"로 남겨뒀던 항목. 2026-09-14 교수님 논의 범위가 출발위치·조도·시간변화 3가지였음을
사용자가 직접 확인해줘 — 카메라 배치는 의도적 제외(누락 아님)로
최종 확정.
신규 실기 총량: 100회(위치2·3 그리드 50 + 조도 50),
더 타이트한 근거가 필요하면 위치2·3을 n=10으로 올려 150회 안도 가능(이번 주 시간 여유로 충분).
