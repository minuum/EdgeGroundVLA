## Findings

1. **안전성(Safety) 확보**:
   * MoNa-pi의 연속 출력값에서 발생하던 미세한 az(회전), ly(좌우) 잔차 노이즈가 `snap_monapi_action_to_label` 로직을 통해 완벽하게 제거되었습니다.
   * 이에 따라 로봇이 불필요한 좌우 흔들림 없이 부드럽게 `FWD+L`(60%)과 `FORWARD`(30%) 궤적을 그리며 타겟 오브젝트인 "gray basket" 방향으로 안정적으로 이동했음이 데이터로 검증되었습니다.
2. **stale result discarded (교착 방지)**:
   * 사용자가 주행 정지(STOP)를 누른 시점(Step 22)에 stale한 추론 결과가 즉시 버려지고(`stale result discarded`), 백그라운드 추론 루프가 안전하게 자동 종료(`Inference Stopped`)되는 것을 로그에서 확인했습니다.
   * 이후 복귀(Return to Start) 스레드가 기동되어 20스텝의 역재생(Ramp 제어 적용)을 통해 시작점까지 오차 없이 복귀 완료(`🔄 복귀 시작 -> 복귀 완료`)하였습니다.
3. **네트워크 지연성**:
   * API 서버 환경에서 평균 Latency가 411.51 ms로 제어 루프를 돌기에는 준수한 속도를 기록했으나, 로봇의 선속도가 빠를 경우 400ms의 지연은 약 10~15cm의 제어 오차를 유발할 수 있으므로, 향후 로컬 엣지(VLA Local Engine) 기동을 통해 레이턴시를 100ms 이하로 줄이는 방안을 검토해야 합니다.
