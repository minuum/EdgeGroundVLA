E 종합 — 어떤 factor가 진짜 핵심인가 (최종 순위)

  1. head 구조(LSTM vs MLP) — 가장 강력. hidden state 없이도 baseline 대비 +4.3%p(91.54%→95.87%, CH43-2b).
  2. hidden state 차원 — 2304차원 원시값은 오히려 해롭고, 32차원으로 줄이면 baseline을 넘김(CH43-1).
  3. 그라운딩 품질 — has_bbox 유무로 오류율 3~5배 차이(CH41), head 구조와 독립적으로 작용.
  4. hidden state 유무(LSTM 위에서) — LSTM+hidden(add)이 LSTM-none보다 +0.98%p 추가 개선.
  5. 텍스트 명령(prompt) — 거의 영향 없음, 이미지 신호가 항상 압도(CH42).
처음 가설(hidden state가 핵심)과 달리, 실제 가장 큰 차이를 만든 건 시퀀스 정보를 쓰는 head 구조였다 — MLP는 윈도우 히스토리를 flat하게 펴서 시간 순서를 버리는데 LSTM은 그걸 그대로 활용한다.
