# 로봇 세션 전달 (초안, 사용자 검토 후 전달) — 지시문·물체 교체 시험용 라이브 촬영

> 배경: 교수님(11/05) 요청 — ① 지시문을 바꿔도 가는가 ② 회색 통을 다른 물체로 바꾸고 그 물체 단어를 주면 가는가.
> 오프라인 점검 결과(`docs/v5/egvla2_fm/text_robustness.json`, `figures/ch79/text_phrases_grid.png`): 기존 10/29 사진에는 회색 통 외 물체가 거의 없어,
> 대상이 없는 문구(red chair)에서도 모델이 박스를 추측해 내는지(회색 통을 잡음) 진짜 일반화인지 구분할 수 없다. **실제 물체를 놓은 사진이 필요하다.**

## 1. 1단계 — 정지 사진 촬영(로봇 이동 없이, 카메라만; 약 20~30분)
같은 시작 위치(pos1)에서, 장면 구성별로 로봇 카메라 사진을 각 3장(바구니 위치 G2·G3·G4 높이 정도로 좌/중/우) 찍는다.
| 구성 | 장면 | 목적 |
|:--|:--|:--|
| S0 | 회색 통만 | 기준 |
| S1 | 다른 물체 1개만(통 없음). 물체 후보: 흰 상자, 컵, 의자, 파란 병 중 2~3종 | 물체 교체 시험의 대상 |
| S2 | 통 + 다른 물체 1개 같이(통에서 1 m 이상 떨어뜨림) | 문구가 둘 중 하나를 고르는지(E2E 선택 능력) |
| S3 | 아무 물체 없음(빈 바닥) | 대상 없는 문구에서 박스를 추측하는지 |
- 저장: 기존 H5 형식이 아니어도 됨(JPEG q95 원본 해상도 권장). 파일명 `S{구성}_{물체}_{좌|중|우}_{번호}.jpg`.
- 물체 이름·색을 사진마다 메모(예: "white box", "blue bottle"). 문구는 이쪽에서 정함.

## 2. 이쪽에서 할 일
- 사진마다 문구(물체 이름·동의어·틀린 이름)를 바꿔 Florence-2 그라운딩과 A3 헤드 명령을 계산하고 사진 위 박스로 시각화(사용자가 직접 확인).

## 3. 2단계 — 실기(1단계 결과가 괜찮을 때, 사용자 승인 후)
물체 교체: 회색 통을 치우고 S1 장면에서 그 물체 단어로 시험, 각 5~10회. 서버 설정 변경이 필요하면(문구 인자 전달) 이쪽에서 먼저 코드·계획서를 올린다. **로봇 서버의 문구는 지금 `gray basket`으로 고정되어 있어, 실기 시험에는 서버 수정이 선행되어야 한다.**

## 4. 확인 요청
1. S1·S2에 쓸 물체 종류와 확보 가능 여부.
2. 촬영 가능한 시간(사진만이면 로봇 구동 불필요).
