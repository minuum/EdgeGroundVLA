## 1. 학습으로 메울 수 있는 간극 / 없는 간극
- **학습으로 가능**: (a) 타깃 위치에 반응하는 조향, (b) 시작 회전 포함 하드웨어 의미(회전/이동/정지)에 맞는 출력, (c) 실기가 방문하는 상태 분포(타깃이 가장자리·소실 직전)에서의 행동, (d) 실기 장면(바닥 밝기 +12%)에 대한 견고성.
- **학습 밖(서빙·제어기)**: 속도 70% vs 100%, 회전 정지 특성·시간 구조, SYNC 0.4초 버스트, 램프 펄스 → 로봇 보정 실험(`HANDOFF_20261023_ROBOT_PHYSICAL_CALIBRATION.md`).

## 2. 후보 실험 (E1~E9)
공통: FM-π0(층2·폭128), 서브골 드롭아웃 30%, 120 epoch, 5-fold + 안 본 위치(LOPO) 중 대표 분할, 기준 대비 같은 분할 비교. 비용은 학습 1회 약 4~6분(단독 GPU 기준).

| # | 후보 | 방법 | 사용하는 세션 정보 | 비용 | 기대 | 위험·성공 기준 |
|---|---|---|---|---|---|---|
| E1 | **yaw-shift 증강 + 서보 재라벨** | 학습 프레임을 가로로 s px 이동(실기 회전 한 번 ≈ −68px@320 ≈ Δcx −0.21로 검증됨)해 타깃이 어긋난 장면을 합성하고 Florence-2 특징·bbox를 다시 추출, 어긋남에 맞는 교정 방향으로 라벨 | 회전 버스트의 px↔cx 환산(−68px = −0.207) | 특징 추출 약 6천장 × 변형 3개 ≈ 15~20분 + 학습 | S 상승, 방향 오차 증가 최소 | 가장자리 장면에서 지평선·바닥 시차 미반영. **성공: S ≥ +10°, 사람 방향 오차 증가 ≤ 3°** |
| E2 | **하드웨어 의미 출력(방향각 + 모드)** | 라벨을 (sin θ, cos θ, 모드{이동·회전±·정지})로 바꾸고 크기·속력 단계 제거 | 하드웨어가 크기 무시 | 낮음 | 회전·정지 처리가 서버 규칙 없이 모델 안으로, 크기 낭비 제거 | 시작 회전 분류 정확도 > 85%, 이동 방향 오차 불변 |
| E3 | **조건부 FiLM(bbox 주 조건) + bbox 이동 증강** | bbox를 FiLM으로 특징에 곱하고, 학습 때 bbox만 ±δ 이동시켜 모델이 bbox를 쓰게 강제(특징 불변 라벨 유지 시 위험 → E1 라벨과 결합) | — | 낮음 | S 상승 | 단독으로는 라벨 일관성 부족(이전 특징 드롭이 S 악화), E1과 묶어서만 |
| E4 | **서보 라벨 λ 곡선·seed 확장** | λ ∈ {0.15, 0.3, 0.5, 0.75, 1.0} × seed 3, 5-fold+LOPO | 실기 가장자리 비율 47%를 서보 필요 지점 가중에 사용 | 중(약 75회) | 맞교환 곡선 → 폐루프 비교군 후보 확정 | 곡선의 무릎점 선택 |
| E5 | **실기 상태 가중(가장자리·소실 직전)** | 학습 프레임 중 cx<0.25 또는 >0.75 인 프레임에 가중(실기 구동의 47%가 해당) | 위 분포 | 낮음 | 실기가 가는 곳에서 정확해짐 | 학습 분포에서 해당 프레임이 희소 → 오버피팅 |
| E6 | **규칙 전문가 DAgger-lite** | 실기 세션 프레임(453장)을 서보·회전 규칙(cx 중앙화, 근접 정지)으로 라벨링해 학습에 소량 혼합(도메인 태그) | 세션 이미지·bbox 전부 | 낮음 | 실기 방문 상태 분포 학습 | **라벨이 규칙이므로 규칙 이상은 못 배움**, 표본 453장은 작음 |
| E7 | **서빙 입력 일치(정지 후 영상)** | 학습 프레임 중 직전 2프레임 명령이 0인 프레임만 또는 모션 번짐 제거 증강으로 학습, 정지 후 영상과의 차이 측정 | A2: 학습 영상은 명령 후 2프레임 지연 결과를 담음, 실기 SYNC는 정지 후 | 중 | 입력 분포 일치 | 정지 프레임이 적어 데이터 부족 |
| E8 | **밝기·노출 증강(+12%)** | 학습 프레임 밝기·감마·화이트밸런스 소폭 변환 후 특징 재추출 | 바닥 영역 밝기 학습 123 vs 실기 137 | 추출 약 15분 + 학습 | 분포 이동 완화(작은 효과 예상) | 효과 작아도 저비용 |
| E9 | **경로 의도 헤드 분리** | (왼/직/오른) 의도 확률과 조향 분리, 의도는 시작에서 고정 후 유지(commitment) | 시작 구간 다봉(47%) | 중 | 시작 구간 평균 쏠림·−48° 고정 완화 | 이전 에이전트 의도 실험: 틀리면 방향 오차 +7~9° |

## 3. 평가: 오프라인 "간극 지표" 5종 (방향 오차만으로는 폐루프를 못 봄)
1. **반사실 민감도 S**(타깃 cx ±0.2 이동 시 교정 방향 각도) — 목표 ≥ +10°
2. **시작 회전 재현**: 학습 시작 구간에서 회전/이동 분류 정확도와 az 부호 일치
3. **실기 상태 일치**: 실기 세션 프레임 453장에서 규칙 전문가(서보·회전)와의 방향 일치율(기준 모델의 현재값 먼저 측정)
4. **오버슈트 시뮬**: 학습 프레임에 yaw 이동을 적분하는 소형 폐루프 시뮬(이동량은 −0.207/버스트로 보정)에서 중앙 수렴·오버슈트 비율
5. **사람 방향 오차**(기존): 증가폭 상한 3°

## 4. 실기 검증(오프라인 통과 후)
- 비교군: 기준 / 기준 + 외부 서보(구현됨, `SERVO_BLEND`) / E1 체크포인트 / E4의 무릎점 λ — pos1 × 5 위치 × 4회 = 20회씩, 속도·구동 모드는 고정(속도 정렬은 별도 축).
- 지표: 성공·소실·개입·소요 시간, 소실 발생률(현재 10/17), 오버슈트율(현재 26%).

## 5. 순서·일정(학습 서버 기준)
1. (0.5일) 평가 5종 구축 + 기준 모델 현재값 측정 — 개선 목표 확정
2. (0.5~1일) E2·E5·E8(저비용) 먼저
3. (1일) E1(특징 재추출 포함) → E3 결합
4. (1일) E4 곡선 → 무릎점 선택
5. (0.5일) E6·E7·E9는 1~4 결과 보고 선택
6. 체크포인트를 `runs/egvla2_fm/deploy/`에 저장·MANIFEST 기록 후 로봇 세션에 rsync 요청

## 6. 한계
- 세션 데이터는 드라이런이며 성공 판정이 없다. 세션에서 모델이 한 행동은 정답 라벨이 아니라 **방문한 상태와 실패 양상**으로만 쓴다(E6의 라벨은 규칙이 만든 것).
- 시뮬·증강 계수(−0.207/버스트, 70%, 지연 2프레임)는 한 번의 측정이고 n이 작다. 로봇 보정 실험 결과로 갱신.
- 오프라인 지표 개선이 폐루프 성공으로 이어지는지는 실기에서만 확인된다.

## 7. 결정 필요
(1) 승인할 후보(권장 순서: 평가 구축 → E2·E5·E8 → E1 → E4), (2) E6에서 규칙 전문가 라벨 사용 여부, (3) 학습 GPU 사용 시간 상한(예: 일 6시간), (4) 폐루프 비교군 수.
