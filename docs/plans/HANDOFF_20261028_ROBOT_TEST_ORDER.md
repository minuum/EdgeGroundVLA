# 로봇 세션 전달 — 10/28 실기 시험 순서 (A1 → A2) (minum 작성)

> 이 문서는 `HANDOFF_20261027_ROBOT_MODEL_ARMS.md`(체크포인트·sha·환경변수·기록 항목)를 전제로 **오늘 실기 시험의 순서와 판정 기준**만 정리한다. 이전 핸드오프의 공통 조건(JPEG q95, EMA 0.5, fp32, apply_cc 끔, 서버 1개)은 그대로 적용. 용어: "조건" = 체크포인트와 환경변수의 한 조합.

## 1. 시험 조건과 순서
| 순서 | 조건 | 체크포인트 (sha 앞 10자리) | 환경변수 | 확인하려는 것 | 횟수 |
|---|---|---|---|---|---|
| 0 | A0 (같은 날 기준선) | `C_pi0_adaln_drop30_e120.pt` (`f88b944fa6`) | 없음 | 오늘 조건에서의 기준선(10/22는 성공률 미측정·날짜 다름) | 5회, A1·A2 사이사이에 끼워 넣기 |
| 1 | **A1** | 위와 같은 파일 | `VLA_EGVLA2_SERVO_BLEND=0.5` | 서버 쪽 서보 혼합만으로 타깃 이탈이 줄어드는가 | 20회 (pos1 × 목표 위치 5종 × 4회) |
| 2 | **A2** | `C_pi0_servolabel0.5_drop30_e120.pt` (`30c78b945c`) | 없음 | 학습된 약한 서보(오프라인 S +3.0°, 사람 방향 오차 +9°)가 폐루프에서 이득인가 | 20회 (같은 구성) |

- **A1에서 소실률이 A0 대비 내려가지 않으면 A2는 건너뛰고 회신**(A2 시간 절약, 원인 좁히기).

- 시험 중 속도(서빙 설정 0.7)와 구동 모드(SYNC)는 모든 조건에서 같게 고정하고 **바꾸지 않는다.**
