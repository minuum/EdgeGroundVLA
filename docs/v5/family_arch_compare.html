0. 3계열 아키텍처 구조 & 네이밍 한눈에 보기

🔵 EGVLA2 · MOD-* (2세대 모듈러)비-E2E · 실기 주력
① Image + Prompt → ② Florence-2 Enc + Decoder generate() → 문자열 <loc> 파싱(BBox) → ③ PiZeroFM → [lx, ly]
• 대표 모델: MOD-A3(a3), MOD-A3-AG(a3-ag23), MOD-DR-Fast(beam=1 fp16), MOD-DR-Safe, MOD-V4R
• EGVLA2 강점: 실기 560+ 세션 검증, 최고 조향 정밀도(0.54°), MOD-DR-Fast 지연 590.7→283.0ms(2.09배 단축), YahBoom 즉시 이식.
• 세대 경계: BBox 문자열 정규식 파싱 경계에서 미분 단절 (환경변수 VLA_EGVLA2_DECODE_MODE=beam1_fp16).
🟡 EGVLA3 대조군 · ENC-E2E-*인코더 단독 E2E · 디코더 제거
① Image → ② DaViT Vision Encoder (LoRA) [BART Decoder 제거] → (선택: Aux BBox 헤드) → ③ PiZeroFM → [lx, ly]
• 대표 모델: ENC-E2E-0(B0), ENC-E2E-1(구 B1), ENC-E2E-AG(EG3-06), ENC-E2E-Aux(EG3-07)
• 역할 (Ablation Baseline): VLM 디코더를 버리고 비전 인코더만 E2E로 학습하면 속도는 빠르나(~30ms) 300ep 바구니 외 Open-Vocab 일반화가 붕괴함을 증명하는 대조군.
🟣 EGVLA3 · VLM-E2E-* (3세대 미분 E2E)완전 미분 E2E · 차세대 연구
① Image + Prompt → ② Florence-2 Enc + BART Decoder(6L) → 1-Pass Hidden 또는 Softmax <loc> 기댓값 → ③ PiZeroFM → [lx, ly]
• 대표 모델: VLM-E2E-Hidden(EG3-08, π0형), VLM-E2E-SoftLoc+(EG3-09/10 + AG23, 296.6ms, 2.71°)
• EGVLA3 강점: 문자열 파싱 0% 완전 미분 E2E + π0형 Hidden E2E의 의자 정지 한계(18.6%)를 미분가능 Soft-Loc 공간 병목으로 돌파(바구니·의자 정지 100%/100%, VLA_EGVLA2_DECODE_MODE=softloc_fp16).
