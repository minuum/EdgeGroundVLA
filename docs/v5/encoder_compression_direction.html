1. 중심 질문

인식 인코더가 지연의 대부분을 차지하는 온디바이스 로봇에서, 학습 없이 인코더를 압축하면 폐루프 성공이 언제, 왜 무너지는가?
이렇게 잡은 이유
  • 10/9 면담에서 받은 방향: VLA 자체보다는 인식 쪽, training-free(추론 수준) 접근도 가능하며, 지금 문제를 학술 질문으로 다시 세울 필요가 있다는 취지.
  • 그래서 행동이 아니라 인식 병목을 중심에 둔다.
  • 기존 측정과 일치: 지연의 97%가 OWLv2.
학술 질문이 되는 지점
  • 압축 연구는 보통 오프라인 정확도로 평가한다.
  • 그러나 에피소드당 평균 11.64회 다시 판단하는 폐루프는 압축으로 생긴 오류를 흡수할 수도, 증폭할 수도 있다.
  • 가설과 반증 조건을 함께 제시한다.

2. 준비 자료

자료내용
질문 구성 조사논문 8편을 "이어받은 질문 → 다시 세운 질문 → 검증 방식"으로 분석해 패턴 4개를 도출하고, 각 패턴을 우리 데이터에 적용해 질문 후보를 만듦. 학습 없는 병합 연구(HOMER) 포함.
2주 실험 계획① 지연 분해 → ② 학습 없는 압축 → ③ 녹화 에피소드로 오프라인 대리 평가. 목표: 곡선 초안 1장 + 표 1개.
미팅 운영30분 아젠다, 여쭐 질문 4개, 예상 질문과 답변 5개(예: "TensorRT면 되지 않나?", "왜 YOLO-World로 안 바꾸나?").

4. 현재 EGVLA2 작업과의 관계

  • EGVLA2는 OWLv2+Kosmos-2를 Florence-2 하나로 교체한 방향(젯슨 fp32 1971→817ms, 2.41×). 현재 지연 병목은 Florence-2 그라운딩(젯슨 821ms, 왕복의 94%).
  • "학습 없는 압축"의 대상을 OWLv2(EGVLA1, 실기 92%)로 할지 Florence-2(EGVLA2)로 할지 미팅 전에 정할 필요가 있다. EGVLA1은 실기 기준선과 녹화 에피소드가 있어 대리 평가가 바로 가능하고, EGVLA2는 지연 병목이 명확하다.
  • 폐루프 흡수/증폭을 보는 대리 평가에는 연구 로그 CH77의 리플레이 시뮬레이션(누적 위치 오차)과 사람 일치도 천장 방법을 재사용할 수 있다.
