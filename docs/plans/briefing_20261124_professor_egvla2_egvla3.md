## 1. Background: 한눈에 보는 전체 흐름 (1분 요약)

1. **EGVLA1 (`G1`, 515ep, 실기 92%)**: OWLv2 + Kosmos-2 **이중 백본** + 이산 8방향 MLP → 무겁고 연속 조향 불가.
2. **EGVLA2 (`G2/G4`, `MOD-*`, 300ep)**: 단일 경량 VLM **Florence-2(0.23B)** + **Flow Matching (`PiZeroFM`)**으로 통합.
   - **현재 실기 성과**: `a3`(455/455) → `a3-s2`(45/45) → **`a3-ag23` (`MOD-A3-AG`) + `beam=1 fp16` (`MOD-DR-Fast`, `285ms`)**로 실기 문제(중앙 비출발 · 근접 접촉 · 지연시간) 해결.
   - **언어 게이트 (`V4R`)**: 비목표 지시어 `99.5%` 정지 + 박스 반전 `94.3%` 방어.
   - **한계**: Florence-2가 **문자열 `<loc>`**를 생성하고 정규식으로 파싱하는 **비미분 2단계 모듈러** 구조.
3. **EGVLA3 (`G3`, `VLM-E2E-*`, 300ep)**: 문자열 파싱을 제거하고 **VLM Decoder → Action Expert를 완전 미분 가능하게 직결한 진정한 E2E VLA**.
   - **핵심 학술 발견**: $\pi_0$형 순수 Latent E2E(`Hidden`)는 300ep에서 미학습 물체 정지(`18.6%`)에 실패하지만, **미분가능 Soft-Loc 공간 병목 + KL 증류 공동 역전파(`EG3-11`)**를 도입하면 Open-Vocab(`99.8%`)과 근접 정지(`100%/98%`)를 동시에 달성.

## 3. Findings: 교수님께 드릴 핵심 논증 3가지 (주장 → 근거 → 데이터)

1. **주장 1 (Dual-Shortcut 규명 및 해소)**: *"기존 VLA의 실패는 VLM이 아니라 Action Head가 768-d 이미지 외형을 정지 지름길로 쓴 탓이다."*
   - **근거**: 동일 BBox에 바구니 이미지 특징만 교체하면 `a3`도 의자 중앙에서 전진(`0.04 → 0.90`).
   - **데이터**: 면적 기하 정합 + 50% 특징 교체(`A3C_AG23_s0.pt`)로 의자 중앙 출발 `0% → 100%`, 근접 정지 `58% → 93%`, T7 각도 `0.54°` 동시 달성.
2. **주장 2 (저데이터 E2E VLA의 구조적 해법)**: *"소규모(300ep) 데이터에서 VLM을 진짜 활용하는 E2E VLA는 $\pi_0$형 Latent 연결이 아니라 **미분 가능한 공간 병목(`Soft-Loc`)**이 필수다."*
   - **근거**: 동일 Florence-2 Decoder에서 Hidden만 넘긴 `EG3-08` vs `<loc>` Softmax 기댓값을 넘긴 `EG3-09/10/11` 정면 Ablation.
   - **데이터**: 미학습 의자 근접 정지 **`18.6% → 98~100%` (+80%p)**, 문자열 파싱 0%, 속도 `2.08배` 가속(`296.6ms`).
3. **주장 3 (공동 역전파와 망각 방지)**: *"Action Loss를 VLM Decoder까지 역전파해도 KL 증류를 결합하면 Zero-Shot Open-Vocab 지식이 전혀 손상되지 않는다."*
   - **데이터 (`EG3-11`)**: 순수 Action Loss 역전파 `grad norm = 0.142255` 실측 확인 + Held-Out 11/13(의자·책상·화분 870장) 검출률 **`99.8%`** 유지(동결 대비 오히려 향상).
