## 1. 데이터 규칙
1. 학습 세트 `egvla2_v3_main` = `action_space=egvla2_continuous_v3` **이면서 검증 통과**한 파일만. v1(40건, 아카이브)은 제외. v1/v2/v3 혼합 금지.
2. 파일럿 v2(15ep)는 가이드 이전 데이터라 **방향·경로 학습에는 포함 가능, 속력 분석에는 제외**(신규만으로 분리 집계).
3. 검증 불통과 파일(깨진 H5, 프레임 간격 이상, 방향 반전 의심)은 목록으로 남기고 제외. 삭제는 로봇 세션(원본 보유자) 판단.
4. **회전 우선 규칙**: |az|>0.1이면 exec는 이동 0·az=±단계. 학습 타깃은 이 규칙이 적용된 `actions_exec`이므로, 이동+회전 동시 입력 프레임(전체 az 프레임의 약 절반)은 "이동 라벨이 사라진 프레임"이다. 이것을 라벨 특성으로 문서화하고, 대안(raw로 학습)은 S1 보조 비교로만 다룬다.
5. 대용량 이미지는 커밋하지 않는다. 캐시(`v3_florence2_cache.npz`)는 크기 확인 후 판단.

## 2. 분할
- 에피소드 단위 분할(프레임 단위 금지). 5 위치(center, weak_left, strong_left, weak_right, strong_right) × 3 경로(left_curve, right_curve, straight) = 15칸.
- **기본**: 5-fold, (위치, 경로) stratified.
- **일반화 점검**: leave-one-position-out(5회), leave-one-path-out은 직선 일반화 확인용(보조).
- 모든 비교는 같은 fold·같은 seed 5개.

## 3. 학습 단계 (각 단계가 끝나야 다음으로, 단계마다 사용자 확인)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| S1 | 베이스라인 재시험: MLP 회귀 vs FM A / B2 / C. 입력 bbox 3프레임 창+F2 풀링. **inner-val 조기 종료**(파일럿에서 최종 epoch가 최저점보다 악화), 5 seed | 평균 기준선 대비 축별 MSE·R² 개선이 fold 간 일관 |
| S2 | 서브골 FiLM(bbox)+연속 타깃 vs concat. V6 Stage2 결과(+1.66%p)가 연속 데이터에서도 유지되는지 | steered가 concat 대비 개선(부호 검정) |
| S3 | 속력 판정: 신규 데이터의 속력~바구니 면적 상관 ρ. |ρ|≥0.3이면 속력 모델 학습, 아니면 rule/섀도 | 판정 기준(제안값, 임의) 적용 |
| S4 | 연속→8-class 변환해 기존 PM과 병기(V6 대비), 오프라인 지표 최종 정리 | 비교표 완성 |

학습 타깃은 `actions_exec` H=8 청크(보조 `actions_scaled`). 샘플링은 Euler 10스텝, 평가 시 K개 평균과 단일 샘플을 둘 다 보고(파일럿에서 단봉 확인).

## 10. az 스파이크 영향 (재수집 없이 진행하는 근거와 대응)
- 스파이크 = 이동 입력 없이 az만 짧게(1~2프레임) 눌린 구간. 조이스틱 센터링·조작 중 우발 입력 성격.
- 학습 영향: az 축 타깃이 희소·잡음이라 R²가 음수(파일럿 −0.1~−0.3). 청크(H=8) 안에 고립 회전 프레임이 섞여 방향 이동 라벨의 신호는 오염되지 않으나, 회전 우선 규칙 때문에 그 프레임의 이동 라벨은 0이 된다(해당 프레임만 정지로 학습).
- 추론 영향: 모델이 작은 az를 내면 |az|>0.1 규칙에서 제자리 회전이 걸릴 수 있음 → 첫 적용 az=0으로 차단.
- 대응(재수집 없음): ① 학습 시 az 축 손실 가중을 낮추거나 보조로만 사용 ② 고립 스파이크를 마스킹한 타깃을 파생(`actions_exec`는 원본 유지)해 비교 ③ 평가에서 az는 비영 프레임 수와 함께만 보고.
