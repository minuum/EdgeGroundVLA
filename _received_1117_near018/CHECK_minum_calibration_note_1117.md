# minum 보정 메모 확인 (soda, 11/17 데이터 기준)
요청된 "11/17 시험의 면적 시계열"은 이미 있음: sessions_1117_near018_area.json(프레임별 area), calibration_pairs_1117.csv(동환 cm와 세션 매칭).

## 확인된 것
- 의자 접촉 면적 0.40~0.50 가정은 11/17 데이터와 충돌함: 의자는 모두 안 부딪힘(+25~35cm)인데 마지막 프레임 면적이 이미 0.36~0.50. 즉 0.40~0.50은 접촉이 아니라 25~35cm 거리의 면적. 동환이 이상적이라는 15~20cm는 더 큰 면적일 것(미관측).
- 바구니 cm↔면적이 단조롭지 않음: +1cm 세션의 마지막 면적 0.996, +5cm 세션은 0.213/0.418. 접촉(−3, −2, −3) 면적은 0.996/0.310/0.640. 한 점 보정은 노이즈가 큼.
- 정지(첫 STOPPED) 이후에도 면적이 계속 변함(예: 0.345→0.745→0.996). 실제 최종 위치와 매칭하려면 첫 STOPPED 값이 아니라 마지막 프레임 값이 맞을 가능성이 높음(둘 다 CSV에 기록).

## 가정/한계
- cm↔세션 매칭은 동환 보고 순서와 세션 시각 순서가 같다고 가정한 것. 바구니 오른쪽은 보고 값에 −가 2개라 4/5와 불일치(동환 확인 필요), CSV 실패는 3번째 1건뿐.
- cm는 손측정. 면적은 grounding bbox(area)이며 오검출 시 값이 튈 수 있음.
- 의자 가까이 붙여본 시험은 없음(의자 접촉 데이터 0건).
